Los hooks son funciones que implementas y FLX llama en sus fases. Las utilidades son operaciones que invoca tu script. Scripting explica cómo asociar scripts a las declaraciones del proyecto.

La referencia canónica del hook collision() pertenece a Collision. Las funciones de esta página que reciben object utilizan una vista válida para la invocación actual.

Hooks · Utilities

Hooks

Implementa born, action, motion, collision(), draw y dead según lo que necesite el objeto. FLX los llama; no son comandos ordinarios que debas invocar. hide() no detiene los hooks de lógica o movimiento.

born()

Firmas
born(object: RuntimeObject): void;

Hook que implementa el desarrollador. FLX lo llama cuando la instancia entra en World, tanto para hijos auto como para instancias solicitadas con spawn. Úsalo para inicializar el estado de esa instancia.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: no devuelve un resultado a FLX (void).

Ejemplo JavaScript
function born(object) {
  write_local(object, "lives", 3);
}

Relacionados: spawn(), action().

action()

Firmas
action(object: RuntimeObject): void;

Hook opcional de lógica por frame. FLX lo invoca en la fase action antes de motion; no necesitas llamar action desde tu script para participar en el ciclo.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: no devuelve un resultado a FLX (void).

Ejemplo JavaScript
function action(object) {
  if (input_pressed(object, button(0))) spawn(object, "laser");
}

Relacionados: motion(), born().

motion()

Firmas
motion(object: RuntimeObject): void;

Hook opcional de movimiento por frame. FLX lo invoca en la fase motion. Las operaciones Mechanics que integran movimiento ya incorporan delta.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: no devuelve un resultado a FLX (void).

Ejemplo JavaScript
function motion(object) {
  move_horizontal(object, input_direction(object, direction(0), HORIZONTAL));
}

Relacionados: action(), advance(), delta().

draw()

Firmas
draw(object: RuntimeObject): void;

Hook opcional de dibujo llamado por FLX. Las primitivas inmediatas emitidas durante esta invocación pertenecen a object, incluso si otra vista se utiliza como referencia espacial. Se vuelven a emitir en los frames en que deban verse.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: no devuelve un resultado a FLX (void).

Ejemplo JavaScript
function draw(object) {
  draw_text(object, 0, -12, object.name);
}

Relacionados: draw_text(), depth(), hide().

dead()

Firmas
dead(object: RuntimeObject): void;

Hook final llamado una vez antes del cleanup de la instancia. Aunque alive es false, el objeto recibido es deliberadamente un contexto válido durante este hook para operaciones permitidas, como spawn, read_local, play_sound, find_parent y find_children. Las búsquedas devuelven sólo familiares que sigan vivos. Esto no prolonga la validez de vistas guardadas de hooks anteriores.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: no devuelve un resultado a FLX (void).

Ejemplo JavaScript
function dead(object) {
  play_sound(object, "explosion");
  spawn(object, "debris");
}

Relacionados: kill(), RuntimeObject.

Utilities

delta()

Firmas
delta(): number;

Devuelve el tiempo efectivo entre frames en segundos. FLX limita los spikes anormales; no es un reloj de tiempo real sin límite. Para move_horizontal, move_vertical, advance, accelerate y rotate no multipliques otra vez la intención por delta.

Retorno: number.

Ejemplo JavaScript
const elapsed = Number(read_local(object, "elapsed") ?? 0) + delta();
write_local(object, "elapsed", elapsed);

Relacionados: motion().

random()

Firmas
random(min: number, max: number): number;

Devuelve un número entre min y max; puede ser fraccionario. Usa límites numéricos ordenados y no lo interpretes como un generador exclusivo de enteros.

min: number
Límite inferior.
max: number
Límite superior.

Retorno: number.

Ejemplo JavaScript
apply_angle(object, random(0, 360));

Relacionados: probability().

probability()

Firmas
probability(chance: number, base?: number): boolean;

Devuelve un booleano según chance sobre base, con base=100 por defecto. Usa cantidades enteras: chance ≤ 0 o base ≤ 0 da false; chance ≥ base da true. No escala automáticamente la probabilidad por tiempo: repetir la consulta cada frame cambia cuántas oportunidades hay.

chance: number
Casos favorables enteros.
base?: number
Total de casos; 100 por defecto.

Retorno: boolean.

Ejemplo JavaScript
if (probability(1, 6)) console.log("Una oportunidad entre seis");

Relacionados: random().

console.log()

Firmas
console.log(...values): void;

Servicio de logging de FLX. Acepta varios valores, los convierte a texto y los une con espacios para emitir un mensaje de script. La salida por consola depende de la configuración de logs de la ejecución; no implica una consola de navegador completa.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
console.log("Ship position:", object.x, object.y);

Relacionados: delta().

exit()

Firmas
exit(): void;

Solicita el cierre ordenado del runtime actual. No equivale a kill, que destruye una instancia.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
if (input_pressed(system(), button(0))) exit();

Relacionados: kill(), system().
