Visual · JSON Reference

visual

Object or block reference with a base color, drawing depth and a list of representation elements. Without visual, no visual representation is declared. A block without representation or with an empty array adds no primitives by itself.

  • color — string. Optional. Base color for elements that do not declare their own.
  • depth — integer. Default: 0. Lower values are drawn first.
  • representation — array of elements. Optional. Each element belongs to exactly one family: primitive, geometry or text.
Minimal visual
{
  "size": {
    "width": 24,
    "height": 24
  },
  "visual": {
    "representation": [
      {
        "primitive": "ellipse"
      }
    ]
  }
}

color

The priority is element color → visual.color → white. Hexadecimal strings are supported: #RGB and #RRGGBB, along with the following case-insensitive names:

lightgray, lightgrey, gray, grey, darkgray, darkgrey, yellow, gold, orange, pink, red, maroon, green, lime, darkgreen, skyblue, blue, darkblue, purple, violet, darkpurple, beige, brown, darkbrown, white, black, blank, magenta, raywhite.

An unknown color generates a warning and uses the fallback. JSON strings always require quotes.

Base color and override
{
  "size": {
    "width": 20,
    "height": 20
  },
  "visual": {
    "color": "#5fffd2",
    "representation": [
      {
        "primitive": "rectangle"
      },
      {
        "primitive": "ellipse",
        "color": "white",
        "size": {
          "width": 8,
          "height": 8
        }
      }
    ]
  }
}

depth

Integer within visual, default 0. Determines drawing order between Objects: lower values are drawn first, and at equal depth the stable drawing order is preserved. Elements in the same representation array are built in order. Does not define a global layer system.

depth
{
  "visual": {
    "depth": 10
  }
}

representation

Inline array. Two families cannot be mixed within one element. Each family has its own fields; there are no common per-element position or rotation fields. Elements use the Object's position and angle.

primitive

  • primitive — string: rectangle | triangle | ellipse. Required. Selects the primitive.
  • mode — string: fill | outline. Default: fill. Fill or outline.
  • size — object. Optional. Own dimensions or dimensions relative to logical size; see below.
  • color — string. Optional. Base color override.
primitive
{
  "size": {
    "width": 40,
    "height": 24
  },
  "visual": {
    "representation": [
      {
        "primitive": "rectangle",
        "mode": "outline"
      }
    ]
  }
}

Primitive size

Object with optional width and height. Each axis accepts a number or a non-negative percentage such as "50%" or "12.5%". An omitted axis takes the corresponding axis from Object.size; a percentage is calculated relative to that logical axis. If an axis is missing from both the primitive and the Object, the primitive is not built. Percentages therefore require a reference Object.size; if the Object declares no size, declare both primitive axes using numeric values.

Percentage size
{
  "size": {
    "width": 40,
    "height": 20
  },
  "visual": {
    "representation": [
      {
        "primitive": "ellipse",
        "size": {
          "width": "50%",
          "height": "100%"
        }
      }
    ]
  }
}

geometry

  • geometry — nonempty array of points. Required. Each point is {"x": number, "y": number}; both axes are required by the schema. Local coordinates relative to the object's position.
  • mode — string: open | close | fill. Default: open. Open line, closed outline or fill.
  • color — string. Optional. Base color override.

Geometry does not support size: the points determine its drawing without resizing the Object's logical size.

geometry
{
  "visual": {
    "representation": [
      {
        "geometry": [
          {
            "x": 0,
            "y": -12
          },
          {
            "x": 10,
            "y": 10
          },
          {
            "x": -10,
            "y": 10
          }
        ],
        "mode": "close"
      }
    ]
  }
}

text

  • text — string. Required. Displayed content.
  • fontSize — integer ≥ 1. Required; no contractual default. Font size.
  • color — string. Optional. Base color override.

Text does not support mode or size. Size is explicitly expressed through fontSize; the block does not declare automatic fitting to the logical box.

text
{
  "origin": {
    "x": 160,
    "y": 30
  },
  "visual": {
    "representation": [
      {
        "text": "READY",
        "fontSize": 20,
        "color": "white"
      }
    ]
  }
}

Visual geometry and colliders are independent declarations.
