A small data-driven 2D engine

Build scenes with JSON. Extend behavior with JavaScript. Keep the core fast and structured in C++.

Get Started Examples GitHub

How FLX works

JSON

Define scenes, entities and configuration.

JavaScript

Control behavior, events and gameplay logic.

C++

Run the engine core, rendering and low-level systems.

Getting Started

scene.json
{
  "scene": "pong",
  "entities": [
    {
      "type": "sprite",
      "id": "player",
      "x": 32,
      "y": 120
    }
  ]
}
player.js
function update(entity, deltaTime) {
  entity.y += entity.speed * deltaTime;
}
Engine.cpp
void Engine::run() {
    while (!windowShouldClose()) {
        update();
        render();
    }
}
