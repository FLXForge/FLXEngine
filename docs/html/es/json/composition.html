Composition · Referencia JSON

Índice | Project | Object | Composition | Visual | Creation | Mechanics | Collision | Audio

Composition describe cómo reutilizar archivos y combinar declaraciones antes de construir el Object. Las referencias se interpretan en los campos que las admiten; un string cualquiera no se convierte en una ruta.

References

  • objects/ship — referencia relativa. En like, children abreviados, bloques referenciables y recursos completos de sonido/música: ruta relativa al archivo usado como contexto por el cargador.
  • /objects/ship — referencia FLX. Parte de la raíz de contenido path del manifiesto, no de la raíz del sistema operativo.
  • /library:member — referencia FLX a miembro. Selecciona una clave de primer nivel del archivo JSON. No es JSON Pointer ni una ruta anidada. Esta sintaxis se procesa en referencias que empiezan por /; no se extiende a referencias relativas.
  • .json — extensión. Opcional. /objects/ship y /objects/ship.json seleccionan el mismo archivo.
Referencias desde un Object
{
  "like": "objects/ship",
  "visual": "/visuals/player",
  "mechanics": "/presets:fast"
}

El ejemplo requiere esos recursos. En una referencia FLX no se admiten segmentos .., incluso si la ruta resultante pudiera permanecer dentro de path. Los errores de lectura, JSON inválido o miembro inexistente se registran como errores de resolución. Literales como white, C4 o enemy conservan su significado en sus respectivos campos.

Bloques referenciables

Como string relativo o FLX se pueden extraer completos visual, mechanics, inherit, bounds, collisions, behavior, creation y states. El archivo puede contener el bloque directamente o envolverlo bajo una clave con el mismo nombre: el cargador extrae esa clave si existe.

player.json
{
  "visual": "/visuals/player"
}
visuals/player.json — bloque directo
{
  "color": "white",
  "representation": [
    {
      "primitive": "triangle",
      "size": {
        "width": 18,
        "height": 24
      }
    }
  ]
}

Las entradas children.<id>, sounds.<id> y music.<id> también admiten referencias relativas o FLX. En sonido se admite un envoltorio sound; en música, music. Los mapas raíz children, sounds y music siguen siendo objetos.

Una entrada individual collisions.<id> admite un string FLX con /; su parser no resuelve un string relativo. La referencia al mapa completo collisions sí admite ambos tipos. attach, origin, size, offset, control y local se declaran inline según el schema.

En Audio, las referencias anidadas a source, tone, movement, note e instrument se resuelven mediante la forma FLX /…. No hay sustitución recursiva universal de todos los strings.

like

String que señala la declaración base. La base se resuelve antes de aplicar las propiedades locales. En Object es una propiedad raíz; también está declarada en los schemas de Sound y Music. Un child abreviado como "ship": "objects/ship" equivale a "ship": { "like": "objects/ship" }.

Objeto derivado
{
  "like": "/objects/ship",
  "origin": {
    "x": 80,
    "y": 90
  },
  "visual": {
    "color": "red"
  }
}

Merge y override

Cuando el valor base y el local son objetos, sus claves se combinan recursivamente. En los demás casos, el valor local sustituye al base. Los arrays se sustituyen enteros: no se concatenan. like se consume durante la resolución. El resultado aún debe ser válido para el bloque de destino; null no es una instrucción de borrado.

Base — ejemplo de combinación
{
  "size": {
    "width": 18,
    "height": 24
  },
  "visual": {
    "color": "white",
    "representation": [
      {
        "primitive": "triangle"
      }
    ]
  }
}
Override local — combinado con la base
{
  "size": {
    "width": 30
  },
  "visual": {
    "color": "red"
  }
}
Resultado de esa combinación
{
  "size": {
    "width": 30,
    "height": 24
  },
  "visual": {
    "color": "red",
    "representation": [
      {
        "primitive": "triangle"
      }
    ]
  }
}

El fragmento de override no es un Object independiente válido: su size parcial necesita el height de la base. Los schemas validan estructuras; no ejecutan el merge. Asimismo, el parser puede resolver like en recursos auxiliares, pero los schemas cerrados de Visual, Mechanics o de los elementos de representación no admiten añadirlo arbitrariamente a sus formas inline.

Contexto de las rutas

Las referencias relativas se interpretan desde el contexto del recurso que las declara. Cuando una composición atraviesa varios archivos, las referencias FLX con / permiten expresar explícitamente una ruta desde path sin depender de la ubicación física del archivo.

Composición recursiva y ciclos

Una base puede tener otra base y los children se resuelven como declaraciones de Object. La composición mediante like debe terminar: las cadenas cíclicas no constituyen una composición válida.
