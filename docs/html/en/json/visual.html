Visual · JSON Reference

visual

Object or block reference with a base color, drawing depth and a list of representation elements. Without visual, no visual representation is declared. A block without representation or with an empty array adds no primitives by itself.

  • color — string. Optional. Base color for elements that do not declare their own.
  • depth — integer. Default: 0. Lower values are drawn first.
  • palette — local map or ordered composition of maps and references. Optional.
  • representation — array of elements. Optional. Each element belongs to exactly one family: primitive, geometry, text or bitmap.
Minimal visual
{
  "size": {
    "width": 24,
    "height": 24
  },
  "visual": {
    "representation": [
      {
        "primitive": "ellipse"
      }
    ]
  }
}

color

For primitive, geometry and text, the priority is element color → visual.color → white. Hexadecimal strings are supported: #RGB and #RRGGBB, along with the following case-insensitive names:

lightgray, lightgrey, gray, grey, darkgray, darkgrey, yellow, gold, orange, pink, red, maroon, green, lime, darkgreen, skyblue, blue, darkblue, purple, violet, darkpurple, beige, brown, darkbrown, white, black, blank, magenta, raywhite.

An unknown declarative color is a compilation error; no fallback color is substituted. JSON strings always require quotes.

Base color and override
{
  "size": {
    "width": 20,
    "height": 20
  },
  "visual": {
    "color": "#5fffd2",
    "representation": [
      {
        "primitive": "rectangle"
      },
      {
        "primitive": "ellipse",
        "color": "white",
        "size": {
          "width": 8,
          "height": 8
        }
      }
    ]
  }
}

depth

Integer within visual, default 0. Determines drawing order between Objects: lower values are drawn first, and at equal depth the stable drawing order is preserved. Elements in the same representation array are built in order. Does not define a global layer system.

depth
{
  "visual": {
    "depth": 10
  }
}

persist · composition order

Base elements accept persist: "first" or "last". Stable first → replaceable section → last grouping is drawn even without playback. Relative order within each group is preserved; without persist, historical order is unchanged. persist is forbidden in key representations and is not duplicated by current capture. A representation: [] key removes only the replaceable section. See the executable persist-order microexample.

The renderer applies Animation appearance to primitive, geometry, text and bitmap with signed/nonuniform local scale, rotation and offset before the world transform. RuntimeObject and immediate drawing are unchanged; rendering never advances time. Explicit colors remain intact; bitmap is never tinted and reuses the World cache. Text retains its font, metrics, spacing, multiline layout and existing sharpness limitations. Project playback still awaits JS bindings and update integration; there is no autoplay.

representation

Inline array. Two families cannot be mixed within one element. Each family has its own fields; there are no common per-element position or rotation fields. Elements use the Object's position and angle.

primitive

  • primitive — string: rectangle | triangle | ellipse. Required. Selects the primitive.
  • mode — string: fill | outline. Default: fill. Fill or outline.
  • size — object. Optional. Own dimensions or dimensions relative to logical size; see below.
  • color — string. Optional. Base color override.
primitive
{
  "size": {
    "width": 40,
    "height": 24
  },
  "visual": {
    "representation": [
      {
        "primitive": "rectangle",
        "mode": "outline"
      }
    ]
  }
}

Primitive size

Object with optional width and height. Each axis accepts a number or a non-negative percentage such as "50%" or "12.5%". An omitted axis takes the corresponding axis from Object.size; a percentage is calculated relative to that logical axis. If an axis is missing from both the primitive and the Object, the primitive is not built. Percentages therefore require a reference Object.size; if the Object declares no size, declare both primitive axes using numeric values.

Percentage size
{
  "size": {
    "width": 40,
    "height": 20
  },
  "visual": {
    "representation": [
      {
        "primitive": "ellipse",
        "size": {
          "width": "50%",
          "height": "100%"
        }
      }
    ]
  }
}

geometry

  • geometry — nonempty array of points. Required. Each point is {"x": number, "y": number}; both axes are required by the schema. Local coordinates relative to the object's position.
  • mode — string: open | close | fill. Default: open. Open line, closed outline or fill.
  • color — string. Optional. Base color override.

Geometry does not support size: the points determine its drawing without resizing the Object's logical size.

geometry
{
  "visual": {
    "representation": [
      {
        "geometry": [
          {
            "x": 0,
            "y": -12
          },
          {
            "x": 10,
            "y": 10
          },
          {
            "x": -10,
            "y": 10
          }
        ],
        "mode": "close"
      }
    ]
  }
}

text

  • text — string. Required. Displayed content.
  • fontSize — integer ≥ 1. Required; no contractual default. Font size.
  • color — string. Optional. Base color override.

Text does not support mode or size. Size is explicitly expressed through fontSize; the block does not declare automatic fitting to the logical box.

text
{
  "origin": {
    "x": 160,
    "y": 30
  },
  "visual": {
    "representation": [
      {
        "text": "READY",
        "fontSize": 20,
        "color": "white"
      }
    ]
  }
}

Visual geometry and colliders are independent declarations.

palette · v0.4.0

Optional local map or ordered composition of maps and references; last definition wins. Exact keys are checked before native colors and may shadow even blank. Values are native colors or hexadecimal literals, never other aliases. Relative, logical and file:member references retain their declaring file; shared maps are never mutated.

bitmap · v0.4.0

Rectangular matrix of 1 to 255 pixels per dimension. Compact strings use single Unicode-character palette keys; explicit arrays accept native names, hexadecimal literals or complete keys. row and pattern accept positive integer repeat (default 1), without recursive patterns. Limits are checked after expansion.

Pivot, angle and composition order are preserved. Size inherits from the object or uses natural matrix dimensions when absent. Elements accept numeric or percentage size like primitives. A bitmap creates no spatial size or collision. Neither visual.color nor element color tints pixels.

Every pixel passes through Machine. blank requests transparency; color.alpha: false may make it opaque. Internal textures require no external assets. The writer uses format 13 and the reader still accepts 12. Dynamic palettes, image imports and bitmap tinting are not supported.

{
  "visual": {
    "palette": [
      "./commons/palette.json",
      {
        "0": "blank",
        "1": "#FF8800"
      }
    ],
    "representation": [
      {
        "bitmap": {
          "pixels": [
            "00100",
            "01110",
            {
              "row": [
                {
                  "pattern": "1",
                  "repeat": 5
                }
              ]
            },
            "01110",
            "00100"
          ]
        }
      }
    ]
  }
}
