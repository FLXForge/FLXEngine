FLX Documentation

FLX API

This section documents the JavaScript functions exposed by FLX to the runtime.

FLX is under active development. Some functions may change during the 0.x versions.

accelerate(object)

Applies acceleration to the object using its motion configuration. It uses acceleration, maxSpeed, angle, velocityX and velocityY.

accelerate
accelerate(ship);

Configuration used

  • motion.acceleration: acceleration force.
  • motion.maxSpeed: maximum allowed speed.
  • angle: current object direction.
  • velocityX and velocityY: accumulated velocity.

accelerate(object, amount)

Direct variant that adds a specific amount to speed. It does not use the advanced motion configuration.

accelerate amount
accelerate(ball, 20);

advance(object)

Moves the object forward according to its current configuration.

If the object has motion.acceleration greater than zero, it uses velocityX, velocityY and inertia. Otherwise, it advances using angle and speed.

advance
function motion(ship) {
    advance(ship);
}

bounce_x(object)

Reverses horizontal movement by modifying the object angle.

bounce_x
bounce_x(ball);

bounce_y(object)

Reverses vertical movement by modifying the object angle.

bounce_y
bounce_y(ball);

console.log(...values)

Sends messages to the internal FLX logger.

console.log
console.log("Ship position:", ship.x, ship.y);

follow_y(object, targetName)

Moves an object vertically to follow another object by name. It compares the vertical center of both objects and adjusts the Y position.

follow_y
follow_y(enemy, "Ball");

Configuration used

  • y: object vertical position.
  • height: object height.
  • speed: follow speed.

Key.down()

Returns true while the down arrow key is pressed.

Key.down
if (Key.down()) {
    move_y(tofu, DOWN);
}

Key.left()

Returns true while the left arrow key is pressed.

Key.left
if (Key.left()) {
    move_x(tofu, LEFT);
}

Key.right()

Returns true while the right arrow key is pressed.

Key.right
if (Key.right()) {
    move_x(tofu, RIGHT);
}

Key.up()

Returns true while the up arrow key is pressed.

Key.up
if (Key.up()) {
    move_y(tofu, UP);
}

move_x(object, direction)

Moves the object horizontally using speed and frame time.

move_x
move_x(tofu, LEFT);
move_x(tofu, RIGHT);

move_y(object, direction)

Moves the object vertically using speed and frame time.

move_y
move_y(tofu, UP);
move_y(tofu, DOWN);

probability(chance, base)

Randomly returns true according to the specified probability.

If base is not specified, the default value is 100.

For example:

  • probability(30) → approximately 30 out of every 100 calls.
  • probability(20, 1000) → approximately 20 out of every 1000 calls.
probability
if (probability(5)) {
    spawn("enemy");
}

if (probability(1, 1000)) {
    spawn("rare_enemy");
}

rotate(object, direction)

Rotates the object using motion.rotationSpeed and frame time.

rotate
rotate(ship, LEFT);
rotate(ship, RIGHT);

to_origin(object)

Restores the object to its origin values. It sets x, y and speed from originX, originY and originSpeed.

to_origin
to_origin(ball);
