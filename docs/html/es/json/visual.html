visual

Objeto o referencia de bloque con color base, profundidad de dibujo y una lista de elementos de representación. Sin visual no se declara representación visual. Un bloque sin representation o con array vacío no añade primitivas por sí solo.

  • color — string. Opcional. Color base de los elementos que no declaran uno propio.
  • depth — integer. Default: 0. Los valores menores se dibujan antes.
  • representation — array de elementos. Opcional. Cada elemento pertenece exactamente a una familia: primitive, geometry o text.
visual mínimo
{
  "size": {
    "width": 24,
    "height": 24
  },
  "visual": {
    "representation": [
      {
        "primitive": "ellipse"
      }
    ]
  }
}

color

La prioridad es color del elemento → visual.color → blanco. Se admiten strings hexadecimales #RGB y #RRGGBB, y los nombres siguientes, sin distinguir mayúsculas:

lightgray, lightgrey, gray, grey, darkgray, darkgrey, yellow, gold, orange, pink, red, maroon, green, lime, darkgreen, skyblue, blue, darkblue, purple, violet, darkpurple, beige, brown, darkbrown, white, black, blank, magenta, raywhite.

Un color desconocido genera un aviso y usa el fallback. Los strings JSON siempre llevan comillas.

Color base y override
{
  "size": {
    "width": 20,
    "height": 20
  },
  "visual": {
    "color": "#5fffd2",
    "representation": [
      {
        "primitive": "rectangle"
      },
      {
        "primitive": "ellipse",
        "color": "white",
        "size": {
          "width": 8,
          "height": 8
        }
      }
    ]
  }
}

depth

Entero dentro de visual, default 0. Ordena objetos en el renderer del World; a igual profundidad se conserva el orden estable de dibujo. Los elementos de un mismo array se construyen en orden. No define un sistema global de capas.

depth
{
  "visual": {
    "depth": 10
  }
}

representation

Array inline. No se mezclan dos familias dentro de un elemento. Cada familia tiene sus campos propios; no hay campos comunes de posición o rotación por elemento. Los elementos usan la posición y el ángulo del Object.

primitive

  • primitive — string: rectangle | triangle | ellipse. Obligatorio. Selecciona la primitiva.
  • mode — string: fill | outline. Default: fill. Relleno o contorno.
  • size — objeto. Opcional. Dimensiones propias o relativas al tamaño lógico; véase más abajo.
  • color — string. Opcional. Override del color base.
primitive
{
  "size": {
    "width": 40,
    "height": 24
  },
  "visual": {
    "representation": [
      {
        "primitive": "rectangle",
        "mode": "outline"
      }
    ]
  }
}

size de primitive

Objeto con width y height opcionales. Cada eje acepta un número o un porcentaje no negativo como "50%" o "12.5%". Un eje omitido toma el eje correspondiente de Object.size; un porcentaje multiplica ese eje lógico. Si falta un eje tanto en la primitiva como en el Object, la primitiva no se construye. Para una primitiva sin tamaño lógico, declare ambos ejes numéricos.

Tamaño porcentual
{
  "size": {
    "width": 40,
    "height": 20
  },
  "visual": {
    "representation": [
      {
        "primitive": "ellipse",
        "size": {
          "width": "50%",
          "height": "100%"
        }
      }
    ]
  }
}

geometry

  • geometry — array no vacío de puntos. Obligatorio. Cada punto es {"x": number, "y": number}; ambos ejes son obligatorios según el schema. Coordenadas locales respecto a la posición del objeto.
  • mode — string: open | close | fill. Default: open. Línea abierta, contorno cerrado o relleno.
  • color — string. Opcional. Override del color base.

Geometry no admite size: los puntos determinan su dibujo, sin redimensionar el tamaño lógico del Object.

geometry
{
  "visual": {
    "representation": [
      {
        "geometry": [
          {
            "x": 0,
            "y": -12
          },
          {
            "x": 10,
            "y": 10
          },
          {
            "x": -10,
            "y": 10
          }
        ],
        "mode": "close"
      }
    ]
  }
}

text

  • text — string. Obligatorio. Contenido mostrado.
  • fontSize — integer ≥ 1. Obligatorio; sin default contractual. Tamaño de fuente.
  • color — string. Opcional. Override del color base.

Text no admite mode ni size. El tamaño se expresa explícitamente con fontSize; el bloque no declara ajuste automático a la caja lógica.

text
{
  "origin": {
    "x": 160,
    "y": 30
  },
  "visual": {
    "representation": [
      {
        "text": "READY",
        "fontSize": 20,
        "color": "white"
      }
    ]
  }
}

La geometría visual y los colliders son declaraciones independientes.
