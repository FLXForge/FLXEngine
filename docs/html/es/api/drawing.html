Sin reference, las coordenadas son del espacio lógico del mundo. Con un RuntimeObject primero, son locales a su posición y giran con él. Esa referencia espacial no cambia quién es el owner del draw actual. No son coordenadas físicas multiplicadas por output.scale.

Dibujo inmediato

draw_text()

Firmas
draw_text(x: number, y: number, text: string, size?: number, color?: string): void;
draw_text(reference: RuntimeObject, x: number, y: number, text: string, size?: number, color?: string): void;

Emite texto inmediato durante draw. x, y representan su centro/pivote en coordenadas lógicas. text es el contenido; size vale 10 si se omite y color es blanco por defecto. Con reference, la posición es local a esa vista y el texto gira con ella. La primitiva pertenece al owner del draw actual.

x: number
Coordenada lógica X.
y: number
Coordenada lógica Y.
text: string
Texto que se dibuja.
size?: number
Tamaño de texto; 10 si se omite.
color?: string
Color como cadena; por ejemplo "#ffffff".
reference: RuntimeObject
Referencia espacial local; no sustituye al owner de draw.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function draw(object) {
  draw_text(40, 10, "SCORE: " + (read_global("score") ?? 0));
  draw_text(object, 0, -12, "READY", 10, "#ffffff");
}

Relacionados: draw(), RuntimeObject.

draw_pixel()

Firmas
draw_pixel(x: number, y: number, color?: string): void;
draw_pixel(reference: RuntimeObject, x: number, y: number, color?: string): void;

Emite un píxel lógico inmediato en x/y durante draw. Color blanco por defecto. Con reference, el punto es local y se transforma con esa referencia espacial; el owner sigue siendo el del draw actual.

x: number
Coordenada lógica X.
y: number
Coordenada lógica Y.
color?: string
Color como cadena; por ejemplo "#ffffff".
reference: RuntimeObject
Referencia espacial local; no sustituye al owner de draw.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function draw(object) {
  draw_pixel(10, 10, "white");
  draw_pixel(object, 0, 0);
}

Relacionados: draw_line(), draw().

draw_line()

Firmas
draw_line(x: number, y: number, x1: number, y1: number, color?: string): void;
draw_line(reference: RuntimeObject, x: number, y: number, x1: number, y1: number, color?: string): void;

Emite una línea inmediata entre x/y y x1/y1. Color blanco por defecto. Con reference, ambos extremos son locales y se transforman con la referencia. Sólo tiene efecto durante el draw actual.

x: number
Coordenada lógica X.
y: number
Coordenada lógica Y.
x1: number
Coordenada lógica X del segundo extremo.
y1: number
Coordenada lógica Y del segundo extremo.
color?: string
Color como cadena; por ejemplo "#ffffff".
reference: RuntimeObject
Referencia espacial local; no sustituye al owner de draw.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function draw(object) {
  draw_line(10, 10, 40, 10);
  draw_line(object, -8, 0, 8, 0, "#ffffff");
}

Relacionados: draw_pixel(), draw().

draw_rectangle()

Firmas
draw_rectangle(x: number, y: number, width: number, height: number, color?: string): void;
draw_rectangle(reference: RuntimeObject, x: number, y: number, width: number, height: number, color?: string): void;

Dibuja el contorno (outline), no el relleno, de un rectángulo lógico. x/y es el centro/pivote; width/height son sus dimensiones. Color blanco por defecto. Con reference, el centro es local y el rectángulo gira con la referencia.

x: number
Coordenada lógica X.
y: number
Coordenada lógica Y.
width: number
Ancho en unidades lógicas.
height: number
Alto en unidades lógicas.
color?: string
Color como cadena; por ejemplo "#ffffff".
reference: RuntimeObject
Referencia espacial local; no sustituye al owner de draw.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function draw(object) {
  draw_rectangle(40, 30, 32, 16);
  draw_rectangle(object, 0, 0, 32, 16, "white");
}

Relacionados: draw(), draw_line().

Estado visual runtime

apply_color()

Firmas
apply_color(object: RuntimeObject, color: string): void;

Sobrescribe el color visual vivo de la instancia con color, por ejemplo "#ff0000". No reescribe la representación declarativa JSON ni es el parámetro color de una primitiva inmediata.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
color: string
Color como cadena; por ejemplo "#ffffff".

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
apply_color(object, "#ff0000");

Relacionados: restore_color(), draw_text().

restore_color()

Firmas
restore_color(object: RuntimeObject): void;

Restaura el color visual y la presencia de color declarados al crear la instancia.

object: RuntimeObject

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
restore_color(object);

Relacionados: apply_color().

Fade global

Fade pertenece al runtime completo, no a una instancia. Su alpha y transición son globales; fade_done sólo indica ausencia de transición.

fade_on()

Firmas
fade_on(color?: string): void;

Inicia una transición global desde el alpha actual hasta 1 (opaco), con duración fija de un segundo. Color negro por defecto. Una nueva llamada reinicia la transición desde el alpha alcanzado; no la llames cada frame para iniciar un único fade.

color?: string
Color como cadena; por ejemplo "#ffffff".

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function born(object) {
  fade_on("black");
}

Relacionados: fade_off(), fade_set(), fade_done().

fade_off()

Firmas
fade_off(color?: string): void;

Inicia una transición global desde el alpha actual hasta 0 (transparente), durante un segundo. Color negro por defecto. Para partir de pantalla completamente cubierta, establece primero alpha 1.

color?: string
Color como cadena; por ejemplo "#ffffff".

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function born(object) {
  fade_set(1);
  fade_off();
}

Relacionados: fade_on(), fade_alpha().

fade_set()

Firmas
fade_set(alpha: number, color?: string): void;

Asigna inmediatamente el alpha global limitado a [0, 1], cancela la transición activa y establece el color (negro por defecto). 0 deja visible la escena; 1 la cubre completamente.

alpha: number
Opacidad limitada a [0, 1].
color?: string
Color como cadena; por ejemplo "#ffffff".

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
fade_set(0.5, "black");

Relacionados: fade_active(), fade_alpha().

fade_active()

Firmas
fade_active(): boolean;

Devuelve true mientras hay una transición global de fade activa.

Retorno: boolean.

Ejemplo JavaScript
if (fade_active()) console.log("Transición en curso");

Relacionados: fade_done().

fade_done()

Firmas
fade_done(): boolean;

Devuelve true cuando no hay transición activa, incluso antes de iniciar un fade o tras fade_set. No significa necesariamente pantalla visible: el alpha final puede ser 1.

Retorno: boolean.

Ejemplo JavaScript
if (fade_done()) console.log("Alpha final:", fade_alpha());

Relacionados: fade_alpha(), fade_active().

fade_alpha()

Firmas
fade_alpha(): number;

Devuelve el alpha global actual entre 0 y 1: transparente/visible en 0, completamente cubierto en 1.

Retorno: number.

Ejemplo JavaScript
const alpha = fade_alpha();

Relacionados: fade_set(), fade_done().
