Hooks / Utilities

Hooks are functions you implement that FLX calls during its phases. Utilities are operations your script invokes. Scripting explains how to associate scripts with project declarations.

The canonical reference for the collision() hook belongs to Collision. Functions on this page that receive object use a view valid for the current invocation.

Hooks · Utilities

Hooks

Implement born, action, motion, collision(), draw and dead according to the object's needs. FLX calls them; they are not ordinary commands for you to invoke. hide() does not stop logic or movement hooks.

born()

Signatures
born(object: RuntimeObject): void;

Hook implemented by the developer. FLX calls it when the instance enters World, both for auto children and for instances requested with spawn. Use it to initialize that instance's state.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: does not return a result to FLX (void).

JavaScript example
function born(object) {
  write_local(object, "lives", 3);
}

Related: spawn(), action().

action()

Signatures
action(object: RuntimeObject): void;

Optional per-frame logic hook. FLX invokes it in the action phase before motion; you do not need to call action from your script to participate in the cycle.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: does not return a result to FLX (void).

JavaScript example
function action(object) {
  if (input_pressed(object, button(0))) spawn(object, "laser");
}

Related: motion(), born().

motion()

Signatures
motion(object: RuntimeObject): void;

Optional per-frame movement hook. FLX invokes it in the motion phase. Mechanics operations that integrate movement already include delta.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: does not return a result to FLX (void).

JavaScript example
function motion(object) {
  move_horizontal(object, input_direction(object, direction(0), HORIZONTAL));
}

Related: action(), advance(), delta().

draw()

Signatures
draw(object: RuntimeObject): void;

Optional drawing hook called by FLX. Immediate primitives emitted during this invocation belong to object, even if another view is used as a spatial reference. Emit them again in the frames where they should be visible.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: does not return a result to FLX (void).

JavaScript example
function draw(object) {
  draw_text(object, 0, -12, object.name);
}

Related: draw_text(), depth(), hide().

dead()

Signatures
dead(object: RuntimeObject): void;

Final hook called once before instance cleanup. Although alive is false, the received object is deliberately a valid context during this hook for permitted operations, such as spawn, read_local, play_sound, find_parent and find_children. Lookups return only relatives that remain alive. This does not extend the validity of views stored from earlier hooks.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: does not return a result to FLX (void).

JavaScript example
function dead(object) {
  play_sound(object, "explosion");
  spawn(object, "debris");
}

Related: kill(), RuntimeObject.

Utilities

delta()

Signatures
delta(): number;

Returns the effective time between frames in seconds. FLX limits abnormal spikes; this is not an unlimited real-time clock. For move_horizontal, move_vertical, advance, accelerate and rotate, do not multiply intent by delta again.

Returns: number.

JavaScript example
const elapsed = Number(read_local(object, "elapsed") ?? 0) + delta();
write_local(object, "elapsed", elapsed);

Related: motion().

random()

Signatures
random(min: number, max: number): number;

Returns a number between min and max; it may be fractional. Use ordered numeric bounds and do not treat it as an integer-only generator.

min: number
Lower bound.
max: number
Upper bound.

Returns: number.

JavaScript example
apply_angle(object, random(0, 360));

Related: probability().

probability()

Signatures
probability(chance: number, base?: number): boolean;

Returns a boolean based on chance out of base, with base=100 by default. Use integer quantities: chance ≤ 0 or base ≤ 0 yields false; chance ≥ base yields true. Does not automatically scale probability by time: repeating the query every frame changes the number of opportunities.

chance: number
Integer number of favorable outcomes.
base?: number
Total number of outcomes; defaults to 100.

Returns: boolean.

JavaScript example
if (probability(1, 6)) console.log("One chance in six");

Related: random().

console.log()

Signatures
console.log(...values): void;

FLX logging service. Accepts multiple values, converts them to text and joins them with spaces to emit a script message. Console output depends on the run's log configuration; this does not imply a full browser console.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
console.log("Ship position:", object.x, object.y);

Related: delta().

exit()

Signatures
exit(): void;

Requests an orderly shutdown of the current runtime. This is not equivalent to kill, which destroys an instance.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
if (input_pressed(system(), button(0))) exit();

Related: kill(), system().
