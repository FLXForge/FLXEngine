# Bitmap Patterns

Tejido arcade de 32x20 celdas que combina patrones compactos, patrones explícitos y repetición vertical, sin expandirlos manualmente en JSON.

Ejecutar desde la raíz del repositorio:

```sh
flx run microexamples/drawing/bitmap/bitmap-patterns/bitmap-patterns.flx
```

No requiere entrada ni audio. Cerrar la ventana para terminar.

También puede compilarse y ejecutarse sin los JSON fuente:

```sh
flx compile --output=out/bitmap-patterns.flxc microexamples/drawing/bitmap/bitmap-patterns/bitmap-patterns.flx
flx run-compiled out/bitmap-patterns.flxc
```
