FLX Documentation

Referencia JSON

Esta sección documenta las estructuras JSON utilizadas por FLX para definir el principal, los objetos y sus propiedades.

FLX está en desarrollo activo. Algunos campos pueden cambiar durante las versiones 0.x.

Tipos de JSON

Actualmente FLX utiliza distintos archivos JSON según la función que cumplen dentro del runtime.

  • main: define el punto principal del runtime.
  • node: define contenedor que puede tener otros elementos.
  • drawable: define objetos que pueden representarse visualmente.

Main JSON

El archivo principal organiza la estructura base del runtime.

world.json
{
    "$schema": "tools/schemas/main.schema.json",
    "name": "Main",
    "description": "This is a description.",

    "screen": {
        "title": "Title in window",
        "width": 320,
        "height": 180
    },

    "scale": 3,

    "children": [ ... ],

    "spawns": { ... },

    "program": {
        "scripts": [ "scripts/program" ]
    }
}

Campos

  • $schema: ruta al schema utilizado para validación. [ Opcional ]
  • name: nombre lógico del principal. [ Obligatorio ]
  • description: descripción opcional. [ Opcional ]
  • screen: configuración de ventana o superficie de ejecución. [ Obligatorio ]
  • scale: factor de escala aplicado al renderizado. [ Opcional ]
  • children: lista de estructuras cargados por el principal. [ Opcional ]
  • spawns: definiciones declarativas de spawn asociadas al objeto. [ Opcional ]
  • program: scripts asociados al programa. [ Opcional ]

Screen

El bloque screen define las propiedades básicas de la ventana.

screen
"screen": {
    "title": "Title in window",
    "width": 320,
    "height": 180
}
  • title: título de la ventana. [ Opcional ]
  • width: ancho interno de referencia. [ Obligatorio ]
  • height: alto interno de referencia. [ Obligatorio ]

Children

El campo children permite declarar objetos contenidos por el principal.

children (link)
"children": [ "objects/tofu" ]
children (inline)
"children": [ {"name": "Tofu", ... } ]
children (mix)
"children": [ "objects/tofu" , {"name": "Tofu", ... }, ... ]

Cada valor hace referencia a un objeto que el runtime debe cargar.

Puede referirse como un fichero externo (no es necesario añadir la extensión JSON) o declararse en línea.

Program

El campo program permite declarar scripts con lógica asociada al programa.

children
"program": {
    "scripts": [ "scripts/program" ]
}

Campos

  • scripts: lista de scripts JavaScript (no es necesario incluir extensión) cargados para el objeto.

Node JSON

Un node define un conjunto de objetos, no se representa a nivel visual pero puede contener lógica.

tofu.json
{
    "$schema": "tools/schemas/node.schema.json",
    "name": "Level",
    "description" : "This is a description.",

    "children": [...],

    "spawns": {...}
}

Campos

  • $schema: ruta al schema utilizado para validación. [ Opcional ]
  • name: nombre lógico del principal. [ Obligatorio ]
  • description: descripción opcional. [ Opcional ]
  • children: lista de objetos cargados por el principal. [ Opcional ]
  • spawns: definiciones declarativas de spawn asociadas al objeto. [ Opcional ]

Drawable JSON

Un archivo drawable define un objeto que puede representarse visualmente.

tofu.json
{
    "$schema": "../tools/schemas/drawable.schema.json",
    "name": "Tofu",

    "origin": {
        "x": 157,
        "y": 87
    },

    "shape": {
        "type": "triangle",
        "color": "WHITE",
        "size": {
            "width": 18,
            "height": 24
        }
    },

    "motion": {
      "rotationSpeed": 180,
      "acceleration": 120,
      "inertia": 0.99,
      "maxSpeed": 180
    },

    "bounds": {
      "mode": "wrap",
      "overflow": true
    },

    "spawns": {
        "laser": {
            "prefab": "objects/laser",
            "offset": {
                "x": 0,
                "y": -12
            }
        }
    },

    "group": "paddle",

    "behavior": {
        "scripts": [ "tofu" ]
    }
}

Campos

  • $schema: ruta al schema utilizado para validación. [ Opcional ]
  • name: nombre lógico del objeto. [ Obligatorio ]
  • origin: posición inicial del objeto. [ Opcional ]
  • shape: información visual del objeto. [ Opcional ]
  • motion: configuración de movimiento, si existe. [ Opcional ]
  • bounds: comportamiento del objeto al alcanzar los límites de la pantalla. [ Opcional ]
  • spawns: definiciones declarativas de spawn asociadas al objeto. [ Opcional ]
  • group: grupo lógico asociado al objeto. [ Opcional ]
  • behavior: scripts asociados al objeto. [ Opcional ]

Origin

Define la posición inicial del objeto dentro del runtime.

origin
"origin": {
    "x": 157,
    "y": 87
}

Campos

  • x: Coordenada X (en referencia al origen de coordenadas, esquina superior izquierda) [ Obligatorio ]
  • y: Coordenada Y (en referencia al origen de coordenadas, esquina superior izquierda) [ Obligatorio ]

Shape

Define la representación visual básica del objeto.

shape
"shape": {
    "type": "triangle",
    "color": "WHITE",
    "size": {
        "width": 18,
        "height": 24
    }
}

Campos

  • type: tipo de forma a dibujar. [ Opcional ]
    • block: bloque sólido por defecto. No aplica mecánicas de rotación.
    • rectangle: rectángulo con soporte para rotación y movimiento orientado.
    • triangle: triángulo sin relleno.
    • line: línea definida entre dos puntos.
    • text: texto renderizable.
  • color: color del objeto. [ Opcional ]
  • size: tamaño del objeto. [ Opcional ]

Size

Define el tamaño del objeto.

motion
"size": {
    "width": 18,
    "height": 24
}

Campos

  • width: anchura del objeto en pixels.
  • height: altura del objeto en pixels.

Motion

Define propiedades relacionadas con el movimiento del objeto.

motion
"motion": {
    "inherit": "creation",
    "rotationSpeed": 180,
    "acceleration": 120,
    "inertia": 0.99,
    "maxSpeed": 180
}

Campos

  • inherit: define cómo hereda movimiento el objeto generado. [ Opcional ]
    • none: no hereda movimiento.
    • creation: hereda el movimiento inicial en el momento del spawn.
  • rotationSpeed: velocidad de rotación.
  • acceleration: aceleración aplicada al objeto.
  • inertia: conservación del movimiento.
  • maxSpeed: velocidad máxima.

Bounds

Define comportamiento del objeto al alcanzar los límites de la pantalla.

motion
"bounds": {
    "mode": "wrap",
    "overflow": true
},

Campos

  • mode: modo del comportamiento. [ Opcional ]
    • none: sin comportamiento especial.
    • wrap: al alcanzar un límite, el objeto aparecerá en el lado opuesto manteniendo su dirección.
  • overflow: controla cómo se aplica el comportamiento de límites. [ Opcional ]
    • true: el objeto comenzará a aparecer por el lado opuesto mientras desaparece progresivamente.
    • false: el objeto reaparece inmediatamente al alcanzar el límite.

Spawns

Define objetos que pueden instanciarse dinámicamente desde el runtime.

spawns
"spawns": {
    "laser": {
        "prefab": "objects/laser",

        "offset": {
            "x": 0,
            "y": -12
        }
    }
}

Las definiciones de spawn utilizan prefabs previamente cargados por el runtime.

Campos

  • prefab: ruta del prefab que debe instanciarse. [ Obligatorio ]
  • offset: desplazamiento local aplicado al spawn. [ Opcional ]

El offset utiliza la rotación actual del objeto como referencia.

Behavior

Define los scripts asociados al objeto.

behavior
"behavior": {
    "scripts": [ "tofu" ]
}

Campos

  • scripts: lista de scripts JavaScript (no es necesario incluir extensión) cargados para el objeto. [ Obligatorio ]
