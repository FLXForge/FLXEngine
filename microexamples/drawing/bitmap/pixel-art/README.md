# Pixel Art

Cohete reconocible de 16x20 celdas, matriz compacta y paleta local. No hay imágenes importadas.

Ejecutar desde la raíz del repositorio:

```sh
flx run microexamples/drawing/bitmap/pixel-art/pixel-art.flx
```

No requiere entrada ni audio. Cerrar la ventana para terminar.

También puede compilarse y ejecutarse sin los JSON fuente:

```sh
flx compile --output=out/pixel-art.flxc microexamples/drawing/bitmap/pixel-art/pixel-art.flx
flx run-compiled out/pixel-art.flxc
```
