RuntimeObject is the temporary view of a World instance. Its properties expose live state; the operations on this page and in Mechanics modify it. A JSON definition and a runtime instance serve different purposes.

RuntimeObject

RuntimeObject

A temporary live view during the current hook. Reads reflect runtime changes, but you cannot retain the view for later hooks: it expires when the invocation ends or the instance dies. dead() explicitly receives a valid final context for the dead object during that hook.

Do not store RuntimeObject in local/global state or in variables for reuse in other hooks. Store its id and resolve it again with find_id(). The fifteen public properties are readonly: use API operations to modify state.

function born(object) {
  const target = find_name("target")[0];
  if (target) write_local(object, "targetId", target.id);
}

function motion(object) {
  const id = read_local(object, "targetId");
  const target = typeof id === "string" ? find_id(id) : undefined;
  if (target) follow_x(object, target);
}

Local and global state

ScriptValue

Type
type ScriptValue = number | boolean | string;

Scalar value supported by local and global state. undefined represents a missing read, not a fourth storable type. Use string to store an identity; design scalar keys for structured data. Related: write_local(), write_global(), save().

Local state belongs to an instance. Global state is shared by the runtime. Both store scalars in memory; Persistence adds storage across runs.

read_local()

Signatures
read_local(object: RuntimeObject, key: string): ScriptValue | undefined;

Reads the key key from the local state of object. Returns the stored scalar value or undefined if the key does not exist. This state belongs to that instance, not to every instance of the definition.

object: RuntimeObject
Instance received or resolved during the current hook.
key: string
Value key.

Returns: ScriptValue | undefined.

JavaScript example
const lives = read_local(object, "lives") ?? 3;

Related: write_local(), ScriptValue.

write_local()

Signatures
write_local(object: RuntimeObject, key: string, value: ScriptValue): void;

Stores or replaces key in the instance's local state. value only supports number, boolean or string; it does not store arrays, objects or RuntimeObject views. Does not write a persistence file.

object: RuntimeObject
Instance received or resolved during the current hook.
key: string
Value key.
value: ScriptValue
Value to assign.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
write_local(object, "targetId", other.id);

Related: read_local(), find_id(), save().

Lookup

find_id()

Signatures
find_id(id: string): RuntimeObject | undefined;

Resolves an instance identifier during the current hook. Returns a live RuntimeObject view or undefined if the instance does not exist or is no longer alive. The resulting view expires again when the hook ends.

id: string
Identifier described in this reference.

Returns: RuntimeObject | undefined.

JavaScript example
const id = read_local(object, "targetId");
const target = typeof id === "string" ? find_id(id) : undefined;
if (target) follow_x(object, target);

Related: RuntimeObject, find_name().

find_name()

Signatures
find_name(name: string): RuntimeObject[];

Finds all live instances whose logical name matches name, in World order. The array is a JavaScript snapshot, not a reactive collection; its elements remain temporary views. With no matches it returns [].

name: string
Logical name of the instances to find.

Returns: RuntimeObject[].

JavaScript example
const balls = find_name("ball");
if (balls.length) follow_y(object, balls[0]);

Related: find_id(), find_children().

find_parent()

Signatures
find_parent(object: RuntimeObject): RuntimeObject | undefined;

Returns the live parent of object or undefined. In dead, the dead object is a valid structural context, but the returned parent must still be alive.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: RuntimeObject | undefined.

JavaScript example
const parent = find_parent(object);
if (parent) console.log(parent.id);

Related: find_children(), dead().

find_children()

Signatures
find_children(object: RuntimeObject): RuntimeObject[];

Returns the live direct children, in World order. Excludes declarations not yet instantiated, pending objects, grandchildren and dead children. This is a JavaScript snapshot; do not persist its RuntimeObjects.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: RuntimeObject[].

JavaScript example
for (const child of find_children(object)) {
  hide(child);
}

Related: find_parent(), spawn().

Transform

position()

Signatures
position(object: RuntimeObject, x: number, y: number): void;
position(object: RuntimeObject, contact: CollisionContact): void;

With x, y, places the instance at absolute logical coordinates. With contact, adds to its current position normal × penetration from the contact directed at the object. The correction does not modify angle, speed or velocity and does not produce a bounce. Use a contact whose source is the object you are correcting; multiple contacts do not, by themselves, constitute a physics solver.

object: RuntimeObject
Instance received or resolved during the current hook.
x: number
Logical X coordinate.
y: number
Logical Y coordinate.
contact: CollisionContact
Contact directed at the object receiving the correction.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
position(object, 160, 90);
// Inside collision(object, other, contacts):
if (contacts.length) position(object, contacts[0]);

Related: CollisionContact, collision(), reflect_x().

depth()

Signatures
depth(object: RuntimeObject, value: number): void;

Sets drawing depth (use an integer value). Lower values are drawn first. The JavaScript view observes the new value immediately; the current drawing pass retains the order captured at its start, and the order change takes effect on the next pass.

object: RuntimeObject
Instance received or resolved during the current hook.
value: number
Value to assign.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
depth(object, 10);

Related: RuntimeObject, draw().
