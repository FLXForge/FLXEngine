FLX Documentation

Conceptos básicos

FLX organiza los proyectos mediante estructuras de datos, objetos, scripts y ciclos de vida claramente definidos.

Proyecto

Todo proyecto FLX parte de un archivo principal con extensión .flx.

Este archivo define la estructura general del proyecto:

  • Principal (main)
  • Scripts
  • Configuración
  • Recursos
project.flx
name:Asteroids
version:1.0
flxEngineVersion:0.0.1
main:game.json

Principal (Main)

El principal es el punto de entrada del runtime.

Desde él se organizan objetos, scripts y lógica de ejecución.

El principal puede utilizarse para representar:

  • Un nivel
  • Un menú
  • Una pantalla de carga
  • Un estado concreto del proyecto
  • Una presentación
  • Una narración
  • Y lo que el desarrollador imagine...

Objeto

Los objetos representan elementos activos dentro del runtime.

Un objeto puede:

  • Dibujarse
  • Moverse
  • Colisionar
  • Ejecutar scripts
  • Contener datos

La estructura de un objeto se define normalmente mediante JSON.

ship.json
{
    "name": "Ship",

    "shape": {
        "type": "triangle"
    },

    "motion": {
        "maxSpeed": 180
    }
}

Scripts

FLX utiliza JavaScript para definir comportamientos.

Los scripts tienen acceso al contexto del runtime y pueden reaccionar a distintos momentos del ciclo de vida.

player.js
function action(self) {
    if (Key.up()) {
        accelerate(self);
    }
}

Ciclo de vida

Durante la ejecución, FLX procesa una serie de etapas en cada iteración del bucle principal.

  1. Inicialización de datos
  2. Inicio del runtime
  3. Lectura de inputs
  4. Ejecución de lógica
  5. Procesamiento de movimiento
  6. Gestión de colisiones
  7. Dibujado

Los scripts pueden reaccionar a estas etapas mediante funciones específicas.

lifecycle.js
function start(self) {}
function action(self) {}
function motion(self) {}
function collision(self, other) {}
function draw(self) {}
function end(self) {}
