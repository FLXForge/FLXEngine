mechanics

Objeto o referencia de bloque con reglas de movimiento y rotación. Los scripts aplican intención mediante la API; la declaración no sustituye al comportamiento. Sin el bloque se conservan los defaults: direct, velocidades y aceleraciones cero, inercia cero y movimiento sin cuantización.

mechanics
{
  "mechanics": {
    "type": "polar",
    "motion": {
      "speed": {
        "start": 90,
        "limit": 150
      },
      "acceleration": 120,
      "inertia": 0.99
    },
    "rotation": {
      "angle": 45,
      "speed": 180
    }
  }
}

type

String: direct o polar; default direct. Direct utiliza reglas por ejes horizontal/vertical. Polar utiliza el ángulo del objeto para avance orientado. En el vector polar, 0° apunta hacia arriba y 90° hacia la derecha.

motion

Objeto opcional; todos sus campos son opcionales.

  • speed — number u objeto start/limit. Default: start 0, limit 0. Velocidad inicial y límite. La forma numérica establece start y deja limit en 0.
  • acceleration — number. Default: 0. Tasa de aceleración temporal. La rama acelerada del runtime se activa para valores positivos.
  • inertia — number de 0 a 1. Default: 0. Parámetro de persistencia utilizado por la integración del movimiento.
  • step — number ≥ 0. Default: 0. Cuantiza el desplazamiento aplicado. Cero mantiene desplazamiento continuo.
  • diagonal — string: independent | vector. Default: independent. independent integra ejes por separado; vector normaliza el movimiento diagonal para evitar el aumento de magnitud de la combinación.
  • horizontal / vertical — objeto de overrides. Opcional. Admiten speed, acceleration, inertia y step, con los mismos tipos.

speed

La forma objeto admite start numérico (default 0) y limit numérico ≥ 0 (default 0). Un límite 0 significa sin límite. Si un límite positivo es menor que start, el parser avisa y lo eleva a start. La velocidad lineal se integra con el tiempo en unidades de posición por segundo; la velocidad de rotación se integra en grados por segundo.

speed corto y límite explícito
{
  "mechanics": {
    "motion": {
      "speed": {
        "start": 100,
        "limit": 160
      }
    },
    "rotation": {
      "speed": 180
    }
  }
}

horizontal / vertical

Un campo de eje no declarado toma la regla común de motion. Si se declara speed como objeto parcial, los miembros omitidos parten de la regla común durante el parseo; una forma numérica reinicia limit a 0. Estos overrides describen reglas por eje: no declaran propiedades raíz adicionales.

Override por eje
{
  "mechanics": {
    "type": "direct",
    "motion": {
      "speed": {
        "start": 80,
        "limit": 120
      },
      "acceleration": 100,
      "horizontal": {
        "speed": {
          "limit": 90
        }
      }
    }
  }
}

inertia y step

La retención temporal utiliza inertia^delta para valores entre 0 y 1; los extremos dan 0 y 1. Su aplicación depende de la rama de integración y de si hay intención de movimiento. step redondea cada desplazamiento integrado a múltiplos del paso: no define por sí solo una rejilla de posiciones absolutas. En rotación, el paso se expresa en grados.

rotation

  • angle — number. Default: 0. Ángulo vivo inicial en grados.
  • speed — number u objeto start/limit. Default: start 0, limit 0. Velocidad angular y límite; la forma corta equivale a start con limit 0.
  • acceleration — number. Default: 0. Aceleración angular temporal.
  • inertia — number de 0 a 1. Default: 0. Persistencia de la integración angular.
  • step — number ≥ 0. Default: 0. Cuantización angular; 0 es continuo.
rotation
{
  "mechanics": {
    "rotation": {
      "angle": 90,
      "speed": {
        "start": 180,
        "limit": 240
      },
      "acceleration": 90,
      "inertia": 0.5,
      "step": 0
    }
  }
}

Para recibir ángulo o velocidad desde el parent, use inherit. Para reaccionar a los límites del World, use bounds.
