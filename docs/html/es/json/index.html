Referencia de las declaraciones de FLX Engine v0.3.0: manifiesto .flx, objetos JSON y bloques reutilizables. Español es la fuente canónica. Seleccione un área o vaya directamente a un campo en el índice alfabético.

Índice por áreas

  • Project — Manifiesto .flx, metadatos y rutas de entrada.
  • Object — Contrato raíz y propiedades comunes del Object.
  • Composition — Referencias, like, merge, contexto de rutas y recursión.
  • Visual — Color, profundidad y representación: primitive, geometry, text.
  • Creation — Children, spawn, component, modos de creación, offset, attach e inherit.
  • Mechanics — Movimiento por ejes u orientado, velocidad y rotación.
  • Collision — Colliders, tamaño, filtros de grupos y estados efectivos.
  • Audio — Sound, Music, source, tone, canales e instrumentos.

Convenciones

Cada unidad indica forma, campos, valores, defaults y ejemplos mínimos. Los ejemplos JSON completos se pueden validar contra el schema correspondiente; los que incluyen referencias requieren los recursos señalados. Un default indica el valor al omitir un campo, no una propiedad obligatoria. Los requisitos adicionales de carga o runtime se indican donde afectan al uso.

Los nombres entre <…> representan claves elegidas por el proyecto. parent, child, Object y World mantienen la terminología de FLX. La selección de archivos externos pertenece a Project; sus capacidades y las llamadas de scripting tienen documentación propia.
