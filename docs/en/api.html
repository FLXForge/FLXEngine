FLX Documentation

FLX API

This section documents the JavaScript functions exposed by FLX to the runtime.

FLX is under active development. Some functions may change during the 0.x versions.

Constants

FLX exposes global constants to work with directions and keyboard input in a readable way.

Direction

  • UP: upward direction.
  • DOWN: downward direction.
  • LEFT: left direction.
  • RIGHT: right direction.
  • STOP: neutral or stopped movement.

Keyboard

  • KEY_UP: up arrow key.
  • KEY_DOWN: down arrow key.
  • KEY_LEFT: left arrow key.
  • KEY_RIGHT: right arrow key.
  • KEY_SPACE: space bar.

RuntimeObject Conventions

angle

The angle property represents the current object rotation in degrees.

FLX uses the following convention:

  • 0: up.
  • 90: right.
  • 180: down.
  • 270: left.

accelerate(object)

Applies acceleration to the object using its motion configuration. It uses acceleration, maxSpeed, angle, velocityX and velocityY.

accelerate
accelerate(ship);

Configuration used

  • motion.acceleration: acceleration force.
  • motion.maxSpeed: maximum allowed speed.
  • angle: current object direction.
  • velocityX and velocityY: accumulated velocity.

accelerate(object, amount)

Direct variant that adds a specific amount to speed. It does not use the advanced motion configuration.

accelerate amount
accelerate(ball, 20);

advance(object)

Moves the object according to its current configuration.

If the object has motion.acceleration greater than zero, it uses velocityX, velocityY and inertia. Otherwise, it advances using angle and speed.

advance
function motion(ship) {
    advance(ship);
}

bounce_x(object)

Reverses horizontal movement by modifying the object angle.

bounce_x
bounce_x(ball);

bounce_y(object)

Reverses vertical movement by modifying the object angle.

bounce_y
bounce_y(ball);

console.log(...values)

Sends messages to the internal FLX logger.

console.log
console.log("Ship position:", ship.x, ship.y);

follow_y(object, targetName)

Moves an object vertically to follow another object by name. It compares the vertical center of both objects and adjusts the Y position.

follow_y
follow_y(enemy, "Ball");

Configuration used

  • y: object vertical position.
  • height: object height.
  • speed: follow speed.

Key.down(key)

Returns true while the specified key is pressed.

Key.down
if (Key.down(KEY_UP)) {
    move_y(tofu, UP);
}

if (Key.down(KEY_LEFT)) {
    move_x(tofu, LEFT);
}

Key.pressed(key)

Returns true only on the frame the specified key starts being pressed.

Key.pressed
if (Key.pressed(KEY_SPACE)) {
    spawn(ship, "laser");
}

move_x(object, direction)

Moves the object horizontally using speed and frame time.

move_x
move_x(tofu, LEFT);
move_x(tofu, RIGHT);

move_y(object, direction)

Moves the object vertically using speed and frame time.

move_y
move_y(tofu, UP);
move_y(tofu, DOWN);

probability(chance, base)

Randomly returns true according to the specified probability.

If base is not specified, the default value is 100.

For example:

  • probability(30) → approximately 30 out of every 100 calls.
  • probability(20, 1000) → approximately 20 out of every 1000 calls.
probability
if (probability(5)) {
    spawn(self, "enemy");
}

if (probability(1, 1000)) {
    spawn(self, "rare_enemy");
}

rotate(object, direction)

Rotates the object using motion.rotationSpeed and frame time.

rotate
rotate(ship, LEFT);
rotate(ship, RIGHT);

spawn(object, spawnName)

Creates a prefab instance using a spawn definition declared in the object JSON.

The spawnName parameter identifies which spawn definition should be used.

spawn
if (Key.pressed(KEY_SPACE)) {
    spawn(ship, "laser");
}

Configuration used

  • object: object from which the spawn is executed.
  • spawnName: name of the spawn definition declared in JSON.

to_origin(object)

Restores the object to its origin values. It restores x, y and speed using originX, originY and originSpeed.

to_origin
to_origin(ball);
