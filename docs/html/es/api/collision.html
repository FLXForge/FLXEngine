FLX detecta contactos y los comunica al script. No aplica automáticamente una respuesta física. La detección se configura en JSON · Collision. El script decide qué significa cada contacto y qué hacer con él.

Contactos · Consultas y colliders

Contactos

CollisionContact

Dato readonly de un contacto dirigido a object dentro del hook collision. No es el retorno de ray; para éste consulta RayHit.

Campos readonly
CampoTipoInterpretación
colliderstringNombre del collider del source.
otherColliderstringNombre del collider del target.
normalXnumberComponente X de la normal dirigida para corregir el source.
normalYnumberComponente Y de esa normal.
pointXnumberCoordenada lógica X del punto de contacto.
pointYnumberCoordenada lógica Y del punto de contacto.
penetrationnumberProfundidad de solapamiento; magnitud de corrección sobre la normal.
Normal, punto y penetration: esquema conceptual
Source A                 Target B
┌──────────────┐
│       ┌──────┼──────────────┐
│       │   •  │              │
└───────┼──────┘              │
        └─────────────────────┘
        |<---->|
        penetration

• = punto de contacto (pointX, pointY)
← = normal del contacto para A

corrección de A = normal × penetration
La normal indica dirección; el punto indica lugar.

El diagrama muestra el concepto, no una fórmula universal para elegir el punto geométrico. La operación relacionada position() aplica la corrección del contacto al source; su referencia completa está en Transform.

Multicollider
Object A                    Object B
┌──────────────┐            ┌──────────────┐
│ body         │ ─────────► │ body         │ contacts[0]
│              │            │              │
│ weapon       │ ─────────► │ shield       │ contacts[1]
└──────────────┘            └──────────────┘

collision(A, B, contacts)
                  └── [ contact0, contact1 ]

El ejemplo ilustra dos pares en una llamada. No dependas de un orden fijo ni supongas un único contacto por pareja. With es direccional: la notificación a B requiere sus propias reglas, no se deriva automáticamente de la notificación a A.

collision()

Firmas
collision(object: RuntimeObject, other: RuntimeObject, contacts: CollisionContact[]): void;

Hook implementado por el desarrollador y llamado por FLX. object es el source, other el target y contacts reúne sus contactos dirigidos en esta llamada. Cada collider source selecciona los groups target mediante with; el target no necesita reciprocidad para que source reciba el callback. Una pareja de instancias puede generar varios contactos por sus diferentes colliders. El script decide cualquier separación, daño o reflexión.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
other: RuntimeObject
Instancia target del contacto.
contacts: CollisionContact[]
Contactos dirigidos al source en esta llamada.

Retorno: no devuelve un resultado a FLX (void).

Ejemplo JavaScript
function collision(object, other, contacts) {
  for (const contact of contacts) {
    console.log(contact.collider, contact.otherCollider);
  }
}

Relacionados: CollisionContact, position(), collider_off().

Consultas y colliders

RayHit

Resultado readonly de ray(). Si no hay impacto, ray devuelve undefined. object sigue siendo una vista temporal del hook actual.

Campos readonly
CampoTipoSignificado
objectRuntimeObjectInstancia alcanzada.
colliderstringNombre del collider alcanzado.
pointXnumberCoordenada lógica X del impacto.
pointYnumberCoordenada lógica Y del impacto.
normalXnumberComponente X de la normal en el impacto.
normalYnumberComponente Y de la normal en el impacto.
distancenumberDistancia lógica desde el origen del rayo.

ray()

Firmas
ray(source: RuntimeObject, angle: number, distance: number): RayHit | undefined;

Lanza una consulta desde la posición lógica de source, con ángulo en grados FLX (0 arriba, 90 derecha) y distancia máxima en unidades lógicas. Devuelve el impacto más cercano con un collider efectivo, o undefined si no hay impacto. Usa ángulo y distancia finitos; una distancia cero no produce impacto. No desplaza ni aplica una respuesta física.

source: RuntimeObject
Instancia origen de la consulta.
angle: number
Ángulo en grados FLX.
distance: number
Distancia máxima lógica, finita y no negativa.

Retorno: RayHit | undefined.

Ejemplo JavaScript
const hit = ray(object, object.angle, 100);
if (hit) console.log(hit.object.id, hit.distance);

Relacionados: RayHit, collider_on().

collider_on()

Firmas
collider_on(object: RuntimeObject, colliderName: string): void;

Activa el collider ya declarado con nombre colliderName en la instancia. No crea geometría nueva; un nombre desconocido no añade un collider. Su eficacia sigue dependiendo de la declaración de colisión. No modifica visible.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
colliderName: string
Nombre de un collider declarado.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
collider_on(object, "body");

Relacionados: collision(), ray().

collider_off()

Firmas
collider_off(object: RuntimeObject, colliderName: string): void;

Desactiva el collider ya declarado con nombre colliderName en la instancia. No crea geometría nueva; un nombre desconocido no añade un collider. Su eficacia sigue dependiendo de la declaración de colisión. No modifica visible.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
colliderName: string
Nombre de un collider declarado.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
collider_off(object, "body");

Relacionados: collision(), ray().
