El archivo .flx es el manifiesto del proyecto: declara metadatos, la raíz de contenido y el objeto de entrada. Su formato es texto clave=valor; no es JSON.

Formato .flx

Una propiedad por línea. Se recortan espacios al principio y al final de claves y valores; el primer = separa ambos. Las líneas vacías y las que comienzan con # se ignoran. No se necesitan comillas. Una clave repetida, desconocida o una línea sin = produce un error.

Manifiesto mínimo
root=world

Este mínimo carga world.json junto al manifiesto. El objeto de entrada usa el mismo contrato Object que sus children; el compilador no permite que esa raíz declare component: true.

Campos

  • title — string. Opcional; si está vacío, toma name. Título del proyecto.
  • name — string. Opcional; vacío. Nombre del proyecto.
  • version — string. Opcional; vacío. Versión del proyecto, independiente de la versión del motor.
  • engine — string. Opcional; vacío. Versión objetivo o requisito declarado del motor.
  • path — ruta. Opcional; default '.' . Directorio del contenido JSON, relativo al directorio del manifiesto cuando no es absoluto. Un valor vacío también equivale a ..
  • root — ruta de objeto. Obligatorio y no vacío. Entrada del World, resuelta desde path. La extensión .json es opcional.
  • machine — ruta de archivo YAML. Opcional; Machine interna por defecto. Ruta relativa al directorio del manifiesto, no a path. Aquí solo se declara el archivo que se utilizará.
  • input.mapping — ruta de archivo properties. Opcional; mapping por defecto. Ruta relativa al directorio del manifiesto. Es un punto de entrada al mapping, no una declaración de capacidades de entrada.
  • notes — string. Opcional; vacío. Notas libres del proyecto.

Resolución de rutas

Con path=asteroids y root=space, el objeto raíz es asteroids/space.json desde la carpeta del manifiesto. Una referencia JSON /ui/title parte de esa misma raíz de contenido: asteroids/ui/title.json. Véase References.

Manifiesto real v0.3.0

examples/asteroids.flx
# Game data
title=Asteroids
name=Asteroids
version=2.0
engine=0.3.0

# Configuration
path=asteroids
root=space
machine=machines/asteroidsMachine.yml
input.mapping=controllers.input

# Notes
notes=FLX example with spawn and basic UI

El ejemplo conserva version=2.0 porque es la versión de Asteroids; engine=0.3.0 identifica la versión objetivo de FLX. Los manifiestos actuales de Asteroids y Pong utilizan este formato.
