Composition · JSON Reference

Index | Project | Object | Composition | Visual | Creation | Mechanics | Collision | Audio

Composition describes how to reuse files and combine declarations before constructing the Object. References are interpreted in fields that support them; an arbitrary string does not become a path.

References

  • objects/ship — relative reference. In like, shorthand children, referenceable blocks and complete sound/music resources: a path relative to the file used as context by the loader.
  • /objects/ship — FLX reference. Starts at the manifest's content root path, not the operating system root.
  • /library:member — FLX member reference. Selects a top-level key in the JSON file. This is not JSON Pointer or a nested path. This syntax is processed in references starting with /; it does not extend to relative references.
  • .json — extension. Optional. /objects/ship and /objects/ship.json select the same file.
References from an Object
{
  "like": "objects/ship",
  "visual": "/visuals/player",
  "mechanics": "/presets:fast"
}

The example requires those resources. FLX references do not allow .. segments, even if the resulting path could remain within path. Read errors, invalid JSON or nonexistent members are recorded as resolution errors. Literals such as white, C4 or enemy retain their meaning in their respective fields.

Referenceable blocks

The following can be extracted as complete blocks using a relative or FLX string: visual, mechanics, inherit, bounds, collisions, behavior, creation and states. The file can contain the block directly or wrap it under a key of the same name: the loader extracts that key if present.

player.json
{
  "visual": "/visuals/player"
}
visuals/player.json — direct block
{
  "color": "white",
  "representation": [
    {
      "primitive": "triangle",
      "size": {
        "width": 18,
        "height": 24
      }
    }
  ]
}

The entries children.<id>, sounds.<id> and music.<id> also support relative or FLX references. Sound supports a sound wrapper; music supports music. The root maps children, sounds and music remain objects.

An individual collisions.<id> entry supports an FLX string with /; its parser does not resolve a relative string. A reference to the entire collisions map does support both types. attach, origin, size, offset, control and local are declared inline according to the schema.

In Audio, nested references to source, tone, movement, note and instrument are resolved through the FLX form /…. There is no universal recursive substitution of all strings.

like

String pointing to the base declaration. The base is resolved before local properties are applied. In Object it is a root property; it is also declared in the Sound and Music schemas. A shorthand child such as "ship": "objects/ship" is equivalent to "ship": { "like": "objects/ship" }.

Derived object
{
  "like": "/objects/ship",
  "origin": {
    "x": 80,
    "y": 90
  },
  "visual": {
    "color": "red"
  }
}

Merge and override

When both the base and local values are objects, their keys are combined recursively. Otherwise, the local value replaces the base value. Arrays are replaced in full: they are not concatenated. like is consumed during resolution. The result must still be valid for the destination block; null is not a deletion instruction.

Base — merge example
{
  "size": {
    "width": 18,
    "height": 24
  },
  "visual": {
    "color": "white",
    "representation": [
      {
        "primitive": "triangle"
      }
    ]
  }
}
Local override — merged with the base
{
  "size": {
    "width": 30
  },
  "visual": {
    "color": "red"
  }
}
Result of that merge
{
  "size": {
    "width": 30,
    "height": 24
  },
  "visual": {
    "color": "red",
    "representation": [
      {
        "primitive": "triangle"
      }
    ]
  }
}

The override snippet is not a valid standalone Object: its partial size needs the base's height. Schemas validate structures; they do not perform the merge. Likewise, the parser can resolve like in auxiliary resources, but the closed schemas for Visual, Mechanics or representation elements do not allow it to be added arbitrarily to their inline forms.

Path context

Relative references are interpreted from the context of the resource that declares them. When composition crosses multiple files, FLX references with / let you explicitly express a path from path without depending on the file's physical location.

Recursive composition and cycles

A base can have another base, and children are resolved as Object declarations. Composition through like must terminate: cyclic chains are not valid composition.
