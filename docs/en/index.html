FLX Documentation

Introduction

A small data-driven 2D engine

Build scenes with JSON, define behaviors with JavaScript and let the C++ core handle the rest.

The FLX philosophy: getting results quickly

In FLX, scenes, objects and actors are defined through structured and organized JSON data.

scene.json
{
    "$schema": "../../../tools/schemas/drawable.schema.json",
    "name": "Ship",

    "shape": {
        "type": "triangle",
        "color": "WHITE",
        "size": {
            "width": 18,
            "height": 24
        }
    },

    "motion": {
        "rotationSpeed": 180,
        "acceleration": 120,
        "inertia": 0.99,
        "maxSpeed": 180
    }
}

What it is. Where it exists. How it is built.

Game logic is handled through simple JavaScript scripts.

player.js
/// <reference path="../../../../tools/scripts/flx.d.ts" />

function action(self) {
    if (Key.up()) {
        accelerate(self);
    }
}

function motion(self) {
    advance(self);
}
