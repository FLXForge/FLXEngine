Esta página reúne dos familias independientes: la máquina de estados declarada en JSON y los timers nombrados de cada RuntimeObject. Cambiar de estado no sustituye el script; éste consulta el estado y decide qué operaciones realizar.

State · Timers

State

Las transiciones se declaran en JSON · states. Un componente sin máquina propia puede resolver la máquina de su padre; las consultas y transiciones actúan sobre esa máquina efectiva.

state_to()

Firmas
state_to(object: RuntimeObject, stateName: string): void;

Solicita una transición al stateName declarado y permitido en next del estado actual. Sin máquina o transición válida, conserva el estado. Cuando se acepta, cambia el nombre actual y reinicia el tiempo a 0; state_entered identifica el primer frame completo posterior. No asigna una propiedad arbitraria ni ejecuta un callback automático por estado.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
stateName: string
Nombre declarado de estado.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
if (state_active(object, "title") && input_pressed(object, button(0))) {
  state_to(object, "playing");
}

Relacionados: state_current(), state_entered().

state_entered()

Firmas
state_entered(object: RuntimeObject): boolean;

Devuelve true durante el primer frame completo del nuevo estado. Una transición solicitada en el frame actual prepara ese indicador para el siguiente; no es un evento consumible por la primera consulta.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: boolean.

Ejemplo JavaScript
function action(object) {
  if (state_entered(object)) play_timer(object, "intro", 1);
}

Relacionados: state_to(), state_time().

state_time()

Firmas
state_time(object: RuntimeObject): number;

Devuelve los segundos acumulados desde la entrada al estado, o 0 sin máquina. En action/motion del primer frame completo devuelve 0. Matiz de v0.3.0: World actualiza el tiempo después de las colisiones y antes de draw; una lectura desde draw puede observar ya el delta de ese frame. No se garantiza 0 durante todas sus fases.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: number.

Ejemplo JavaScript
function action(object) {
  if (state_active(object, "playing") && state_time(object) > 5) {
    state_to(object, "finished");
  }
}

Relacionados: state_entered().

Timers

Un timer pertenece a RuntimeObject + nombre y desaparece con su propietario. World actualiza los Running automáticamente; Paused congela el restante. Done permanece observable hasta reproducir, eliminar o destruir el timer.

play_timer()

Firmas
play_timer(object: RuntimeObject, timerName: string, duration?: number): void;

Inicia, reanuda o redefine un timer identificado por object + timerName (cadena no vacía). La duración se expresa en segundos y debe ser finita y mayor que 0. Sin duration: Running no cambia, Paused reanuda, Done vuelve a empezar con su duración conocida y Absent no se crea. Con duration: Absent y Done empiezan con esa duración completa; Running o Paused conservan el tiempo transcurrido y pasan a Running con left = nueva duración total − transcurrido. Si ese restante es ≤ 0, pasan inmediatamente a Done. Duration no es tiempo restante ni una orden universal de reinicio.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
timerName: string
Nombre no vacío del timer del objeto.
duration?: number
Duración total en segundos, finita y mayor que 0; opcional.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
play_timer(object, "gun", 5);
// En una llamada posterior: pausa y reanudación.
pause_timer(object, "gun");
play_timer(object, "gun");

Relacionados: pause_timer(), stop_timer(), timer_done().

pause_timer()

Firmas
pause_timer(object: RuntimeObject, timerName: string): void;

Pausa un timer Running conservando su tiempo restante. No hace toggle: si está Paused, Done o Absent no lo pone en marcha.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
timerName: string
Nombre no vacío del timer del objeto.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript

Firmas
stop_timer(object: RuntimeObject, timerName: string): void;

Elimina inmediatamente el timer del objeto. Queda Absent, no Done; para volver a crearlo necesitas una duración.

Instancia recibida o resuelta durante el hook actual.
timerName: string
Nombre no vacío del timer del objeto.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
stop_timer(object, "gun");

Relacionados: play_timer(), timer_done().

timer_done()

Firmas
timer_done(object: RuntimeObject, timerName: string): boolean;

Devuelve true cuando el timer está Done: normalmente por agotarse, también si play_timer redefine la duración total por debajo del tiempo ya transcurrido. Permanece Done hasta reproducirlo, eliminarlo o destruir su propietario. Absent y stop_timer no son Done.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
timerName: string
Nombre no vacío del timer del objeto.

Retorno: boolean.

Ejemplo JavaScript
if (timer_done(object, "gun")) {
  stop_timer(object, "gun");
}

Relacionados: play_timer(), stop_timer().

timer_left()

Firmas
timer_left(object: RuntimeObject, timerName: string): number;

Devuelve los segundos restantes. En Paused conserva ese valor; en Absent, eliminado o Done devuelve 0. No distingue por sí solo ausencia de finalización.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
timerName: string
Nombre no vacío del timer del objeto.

Retorno: number.

Ejemplo JavaScript
const remaining = timer_left(object, "gun");

Relacionados: timer_done(), timer_active().
