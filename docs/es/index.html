Documentación FLX

Introducción

Un pequeño motor 2D basado en datos

Define estructuras mediante JSON, comportamientos mediante JavaScript y deja que el runtime haga el resto.

La filosofía FLX: datos, funciones y runtime

FLX está construido alrededor de una idea muy sencilla:

Mental model
Objetos -> Datos

Scripts -> Funciones

Runtime -> Conecta ambos

Los objetos definen qué existe.

Los scripts definen qué ocurre.

El runtime conecta ambos durante la ejecución.

ship.json
{
    "$schema": "https://flxforge.github.io/FLXEngine/schemas/drawable.schema.json",

    "name": "Ship",

    "shape": {
        "type": "triangle",
        "color": "white",
        "size": {
            "width": 18,
            "height": 24
        }
    },

    "motion": {
        "rotationSpeed": 180,
        "acceleration": 120,
        "inertia": 0.99,
        "maxSpeed": 180
    }
}

Los datos definen la existencia.

ship.js
/// <reference path="https://flxforge.github.io/FLXEngine/scripts/flx.d.ts" />

function action(ship) {
    if (Key.down(KEY_UP)) {
        accelerate(ship);
    }
}

function motion(ship) {
    advance(ship);
}

Las funciones definen el comportamiento.

FLX no intenta simplificar C++.

Intenta que el comportamiento del runtime pueda escribirse como script.
