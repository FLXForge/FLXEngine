Input

La consulta de entrada combina Subject + Control + Query. El subject identifica quién recibe la entrada, el control qué capacidad lógica se consulta y la query cómo se observa su estado.

Tres responsabilidades
Machine/Input → capacidades lógicas
Input Mapping → dispositivos físicos
API/Input     → consulta lógica

Consulta Machine · Input para capacidades y mapping. Un RuntimeObject actúa como subject mediante su declaración control.player; control no es una propiedad pública de la vista JavaScript. Los índices de jugador empiezan en 1; botones y direcciones, en 0.

Subjects y controles

player()

Firmas
player(playerIndex: number): InputPlayerSubject;

Construye un subject explícito de jugador. playerIndex empieza en 1; el jugador debe existir en Machine/Input para que sus consultas sean válidas.

playerIndex: number
Índice de jugador desde 1.

Retorno: InputPlayerSubject.

Ejemplo JavaScript
const subject = player(1);

Relacionados: InputPlayerSubject, system().

system()

Firmas
system(): InputSystemSubject;

Devuelve el subject de controles globales del sistema. Sólo admite botones; no tiene direcciones.

Retorno: InputSystemSubject.

Ejemplo JavaScript
if (input_pressed(system(), button(0))) exit();

Relacionados: InputSystemSubject, player().

button()

Firmas
button(index: number): InputButton;

Devuelve el descriptor de botón lógico index, empezando en 0. No representa una tecla física ni consulta su estado. El índice debe estar dentro de las capacidades del subject en Machine.

index: number
Índice lógico desde 0.

Retorno: InputButton.

Ejemplo JavaScript
const FIRE = button(0);

Relacionados: InputButton, input_pressed().

direction()

Firmas
direction(index: number): InputDirection;

Devuelve el descriptor de dirección lógica index, empezando en 0. Sus componentes válidos dependen del tipo 2way o 4way declarado en Machine.

index: number
Índice lógico desde 0.

Retorno: InputDirection.

Ejemplo JavaScript
const MOVE = direction(0);

Relacionados: InputDirection, input_direction().

Consultas

input_pressed()

Firmas
input_pressed(subject: InputButtonSubject, control: InputButton): boolean;
input_pressed(subject: InputDirectionSubject, control: InputDirection, component: number): boolean;

Devuelve true en el frame en que el control pasa a activo. subject es un jugador explícito o un RuntimeObject con control.player; los botones admiten también system. Con botón basta subject + control; con dirección debes añadir un componente compatible: UP/DOWN/LEFT/RIGHT para 4way o NEGATIVE/POSITIVE para 2way. Un subject o control fuera de las capacidades no produce una consulta activa.

subject: InputDirectionSubject
Jugador, sistema cuando procede, o instancia con control.player.
control: InputDirection
Descriptor button o direction según la firma.
component: number
Constante compatible con el tipo de dirección.

Retorno: boolean.

Ejemplo JavaScript
if (input_pressed(object, button(0))) {
  console.log("Botón 0");
}
if (input_pressed(player(1), direction(0), LEFT)) {
  console.log("Componente izquierda, dirección 4way");
}

Relacionados: player(), button(), direction().

input_direction()

Firmas
input_direction(subject: InputDirectionSubject, control: InputDirection, axis: number): number;

Devuelve intención lógica -1, 0 o +1 para el eje indicado por HORIZONTAL o VERTICAL. En 4way, LEFT/RIGHT corresponden a X y UP/DOWN a Y; en 2way, NEGATIVE/POSITIVE se proyectan sobre cualquiera de los dos ejes. LEFT, UP y NEGATIVE producen -1; RIGHT, DOWN y POSITIVE producen +1. El neutro devuelve 0. Son valores del resultado, no los valores numéricos de las constantes. No admite system.

subject: InputDirectionSubject
Jugador, sistema cuando procede, o instancia con control.player.
control: InputDirection
Descriptor button o direction según la firma.
axis: number
HORIZONTAL o VERTICAL.

Retorno: number.

Ejemplo JavaScript
move_horizontal(object, input_direction(object, direction(0), HORIZONTAL));

Relacionados: input_down(), HORIZONTAL, VERTICAL.

Tipos de Input

InputButton

Descriptor de un botón lógico, index readonly desde 0. Obtén el descriptor mediante button(). Los marcadores opcionales del archivo de tipos distinguen descriptores; no necesitas construirlos o modificarlos manualmente.

Uso
const control = button(0);

InputDirection

Descriptor de una dirección lógica, index readonly desde 0. Obtén el descriptor mediante direction(). Los marcadores opcionales del archivo de tipos distinguen descriptores; no necesitas construirlos o modificarlos manualmente.

Uso
const control = direction(0);

InputPlayerSubject

Subject explícito de jugador, index readonly desde 1. Obtén el descriptor mediante player(). Los marcadores opcionales del archivo de tipos distinguen descriptores; no necesitas construirlos o modificarlos manualmente.

Uso
const subject = player(1);

InputSystemSubject

Subject único de botones de sistema. Incluye index readonly; su uso público es system(), no seleccionar jugadores con ese índice. Obtén el descriptor mediante system(). Los marcadores opcionales del archivo de tipos distinguen descriptores; no necesitas construirlos o modificarlos manualmente.

Uso
const subject = system();

InputButtonSubject

Tipo
type InputButtonSubject =
  RuntimeObject | InputPlayerSubject | InputSystemSubject;

Subjects admitidos por las consultas de botón. RuntimeObject requiere control.player. Relacionados: input_pressed(), player(), system().

InputDirectionSubject

Tipo
type InputDirectionSubject = RuntimeObject | InputPlayerSubject;

Subjects admitidos por consultas de dirección. System queda fuera. Relacionados: input_direction(), direction().

Constantes

Utiliza los nombres simbólicos; sus valores numéricos internos no forman parte del contrato. Los signos -1/+1 descritos aquí pertenecen al resultado de input_direction.

UP

Tipo
const UP: number;

Componente arriba de una dirección 4way. En la consulta del eje vertical produce intención -1.

Relacionado: input_direction().

DOWN

Tipo
const DOWN: number;

Componente abajo de una dirección 4way. En el eje vertical produce intención +1.

Relacionado: input_direction().

LEFT

Tipo
const LEFT: number;

Componente izquierda de una dirección 4way. En el eje horizontal produce intención -1.

Relacionado: input_direction().

RIGHT

Tipo
const RIGHT: number;

Componente derecha de una dirección 4way. En el eje horizontal produce intención +1.

Relacionado: input_direction().

STOP

Tipo
const STOP: number;

Movimiento neutro/detenido. Puede expresar intención neutra en una operación de movimiento; no sustituye un descriptor button o direction.

Relacionado: input_direction().

NEGATIVE

Tipo
const NEGATIVE: number;

Componente negativo de una dirección 2way. input_direction lo proyecta como -1.

Relacionado: input_direction().

POSITIVE

Tipo
const POSITIVE: number;

Componente positivo de una dirección 2way. input_direction lo proyecta como +1.

Relacionado: input_direction().

HORIZONTAL

Tipo
const HORIZONTAL: number;

Selector de eje horizontal para input_direction. En 4way consulta LEFT/RIGHT.

Relacionado: input_direction().

VERTICAL

Tipo
const VERTICAL: number;

Selector de eje vertical para input_direction. En 4way consulta UP/DOWN.

Relacionado: input_direction().
