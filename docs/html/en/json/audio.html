Audio documents the sounds and music declared in an Object. These resources describe generated content; declaring them does not imply automatic playback. Machine capabilities are external to these blocks and are not configured here.

sounds

Map of identifiers to inline Sound objects or relative/FLX references. Without this block, no sounds are declared. Each identifier can be played through the API, for example play_sound(object, "beep").

sounds
{
  "sounds": {
    "beep": {
      "kind": {
        "note": 880
      },
      "duration": 0.1,
      "volume": 0.4
    }
  }
}

Sound

  • like — string. Optional. Reusable base; see Composition.
  • kind — object. Optional. Source, note and frequency variation.
  • tone — object or FLX reference. Optional. Material, envelope and space.
  • duration — number > 0. Default: 0.1. Duration in seconds.
  • volume — number from 0 to 1. Default: 0.4. Declared volume.
  • priority — integer. Default: 0. Priority used by the runtime when assigning available sound voices.

kind

  • source — object or FLX reference. Default: oscillator, square, duty 0.5. Generating source.
  • note — string, number or frequency object. Runtime default: 440 Hz. Musical note such as A4, numeric frequency in Hz or {"frequency": 440}. Can also be an FLX reference to one of these values.
  • slide — number. Default: 0. Frequency variation in Hz over the sound. A nonzero slide takes priority over rise/fall sliding.
  • movement — object or FLX reference. Default: type none, amount 0. Declared modulation.
kind
{
  "sounds": {
    "laser": {
      "kind": {
        "source": {
          "type": "oscillator",
          "wave": "square"
        },
        "note": "A4",
        "slide": -200,
        "movement": {
          "type": "fall",
          "amount": 0.5
        }
      },
      "duration": 0.15
    }
  }
}

source

  • type — string: oscillator | noise | impact | pulse. Default: oscillator. Source type. The parser forces wave=noise when type=noise.
  • wave — string: sine | square | triangle | saw | pulse | noise. Default: square. Waveform.
  • duty — number from 0.05 to 0.95. Default: 0.5. Pulse wave duty cycle.
source — inside kind or instrument
{
  "type": "pulse",
  "wave": "pulse",
  "duty": 0.25
}

movement

  • type — string: none | rise | fall | pulse | wobble | scatter | random. Default: none. Sound movement type.
  • amount — number from 0 to 1. Default: 0. Normalized intensity.
movement
{
  "type": "wobble",
  "amount": 0.2
}

tone

Object or FLX reference shared by Sound and Instrument. Its three groups are optional; omitting them applies the following defaults.

material

  • brightness — number from 0 to 1. Default: 0.5. Material brightness.
  • roughness — number from 0 to 1. Default: 0. Roughness.
  • noise — number from 0 to 1. Default: 0. Noise component.
  • resonance — number from 0 to 1. Default: 0. Resonance.
  • metal — number from 0 to 1. Default: 0. Metallic component.

envelope

  • attack — number ≥ 0. Default: 0. Attack time in seconds.
  • decay — number ≥ 0. Default: 0.05. Decay time in seconds.
  • sustain — number from 0 to 1. Default: 0. Sustain level.
  • release — number ≥ 0. Default: 0. Release time in seconds.

space

  • mode — string: mono | stereo. Default: mono. Declared spatial mode.
  • width — number from 0 to 1. Default: 0. Declared width.
  • echo — number from 0 to 1. Default: 0. Echo amount.

In the current generator, echo is used in synthesis; mode and width are read and retained, but the generated wave remains mono. Declaring stereo does not guarantee stereo output in this version.

tone
{
  "material": {
    "brightness": 0.8,
    "noise": 0.1
  },
  "envelope": {
    "attack": 0.01,
    "decay": 0.05,
    "sustain": 0.2,
    "release": 0.03
  },
  "space": {
    "mode": "mono",
    "echo": 0.1
  }
}

music

Map of identifiers to inline Music objects or relative/FLX references. Each song requires channels, an object of named channels. Without this block, no music is declared. Playback is requested through the API.

  • like — string. Optional. Reusable base.
  • tempo — number > 0. Default: 120. Tempo in quarter notes per minute.
  • loop — boolean. Default: false. Song looping.
  • channels — object. Required. Channel map.
Minimal music
{
  "music": {
    "theme": {
      "tempo": 120,
      "loop": false,
      "channels": {
        "lead": {
          "notes": [
            "C4",
            "E4",
            "G4",
            "-"
          ]
        }
      }
    }
  }
}

channels

  • notes — array of strings. Required. Sequence of notes for this channel.
  • instrument — object or FLX reference. Optional; Instrument defaults. Channel source and timbre.
  • wave — string: square | sine | triangle | saw | noise. Default: square if there is no other source. Per-channel shorthand. When declared, replaces instrument.source's wave.
  • volume — number from 0 to 1. Default: 1. Channel volume.
  • length — string: 1/1 | 1/2 | 1/4 | 1/8 | 1/16. Default: 1/4. Duration of each notes entry, relative to a whole note. A quarter note (1/4) lasts 60/tempo seconds.

notes

Notes use names from C to B with octaves from 0 to 8, using sharps or flats supported by the converter, for example C#4 and Db4. "-" and "" are rests. "x" or "X" triggers a noise entry only in noise channels; in others it is ignored with a warning. An invalid note or one outside instrument.range becomes a rest with a warning.

Noise channel
{
  "music": {
    "beat": {
      "channels": {
        "drum": {
          "wave": "noise",
          "length": "1/8",
          "notes": [
            "x",
            "-",
            "x",
            "-"
          ]
        }
      }
    }
  }
}

instrument

  • source — object or FLX reference. source defaults. Generating source; the same block as in Sound.
  • tone — object or FLX reference. tone defaults. Material, envelope and space.
  • play.legato — boolean. Default: false. Performance parameter retained by the parser.
  • play.glide — number from 0 to 1. Default: 0. Performance parameter retained by the parser.
  • play.vibrato — number from 0 to 1. Default: 0. Intensity of vibrato applied to frequency during synthesis.
  • range.min — note string. Default: C0. Lower bound of playable notes.
  • range.max — note string. Default: B8. Upper bound of playable notes.

play and range are optional objects. The current generator checks range and applies vibrato. Legato and glide are retained but are not yet applied to wave calculation: they are documented as accepted declarations, without attributing an unimplemented audible effect to them.

Channel instrument
{
  "music": {
    "theme": {
      "channels": {
        "lead": {
          "instrument": {
            "source": {
              "type": "oscillator",
              "wave": "triangle"
            },
            "tone": {
              "envelope": {
                "attack": 0.01,
                "decay": 0.05,
                "sustain": 0.4,
                "release": 0.02
              }
            },
            "range": {
              "min": "C3",
              "max": "C6"
            }
          },
          "length": "1/4",
          "notes": [
            "C4",
            "E4",
            "G4"
          ]
        }
      }
    }
  }
}

Audio references

Complete Sound and Music resources support relative and FLX references, as well as like. Nested references to source, tone, movement, note and instrument follow the same resolution rules. A string such as "square" does not replace a source object: wave must be a source field.

External resources
{
  "sounds": {
    "beep": "/audio/beep"
  },
  "music": {
    "theme": "audio/theme"
  }
}

The Sound and Music schemas are open (additionalProperties: true) in several structures. This allows additional properties during validation, but does not imply the runtime interprets them. This reference lists the fields read by the current implementation. See Composition.
