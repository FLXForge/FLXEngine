The .flx file is the project manifest: it declares metadata, the content root and the entry object. Its format is key=value text; it is not JSON.

.flx format

One property per line. Leading and trailing whitespace is trimmed from keys and values; the first = separates them. Empty lines and lines starting with # are ignored. Quotes are not needed. A repeated or unknown key, or a line without = produces an error.

Minimal manifest
root=world

This minimum loads world.json next to the manifest. The entry object uses the same Object contract as its children; the compiler does not allow that root to declare component: true.

Fields

  • title — string. Optional; if empty, takes name. Project title.
  • name — string. Optional; empty. Project name.
  • version — string. Optional; empty. Project version, independent of the engine version.
  • engine — string. Optional; empty. Declared engine target version or requirement.
  • path — path. Optional; default '.' . JSON content directory, relative to the manifest directory when not absolute. An empty value is also equivalent to ..
  • root — object path. Required and nonempty. World entry, resolved from path. The extension .json is optional.
  • machine — YAML file path. Optional; internal Machine by default. Path relative to the manifest directory, not to path. Only the file to use is declared here.
  • input.mapping — properties file path. Optional; default mapping. Path relative to the manifest directory. This is an entry point to mapping, not a declaration of input capabilities.
  • notes — string. Optional; empty. Free-form project notes.

Path resolution

With path=asteroids and root=space, the root object is asteroids/space.json from the manifest folder. A JSON reference /ui/title starts from that same content root: asteroids/ui/title.json. See References.

Actual v0.3.0 manifest

examples/asteroids.flx
# Game data
title=Asteroids
name=Asteroids
version=2.0
engine=0.3.0

# Configuration
path=asteroids
root=space
machine=machines/asteroidsMachine.yml
input.mapping=controllers.input

# Notes
notes=FLX example with spawn and basic UI

The example retains version=2.0 because it is Asteroids' version; engine=0.3.0 identifies the target FLX version. The current Asteroids and Pong manifests use this format.
