Mechanics

Movement operations integrate the frame delta. The apply operations change live state; follow and carry act in the current call, while attach enables declared persistent following. For direct positioning or resizing, see Transform.

FLX angles are expressed in degrees: 0 up, 90 right, 180 down, 270 left. Limits, acceleration, inertia and steps are configured in JSON · Mechanics. Choose the operation that represents the desired movement; combining integrators in the same frame can add displacements.

Direct movement

move_horizontal()

Signatures
move_horizontal(object: RuntimeObject, intent: number): void;

Moves along the X axis during this frame and updates its live velocity. intent is clamped to [-1, 1]. With axis acceleration it accumulates velocity; without it, it uses intent × speed. Respects the limit, step and diagonal policy declared in mechanics. With neutral intent, the declared acceleration/inertia determine velocity retention. Integrates delta internally.

object: RuntimeObject
Instance received or resolved during the current hook.
intent: number
Numeric intent clamped to [-1, 1].

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
move_horizontal(object, input_direction(object, direction(0), HORIZONTAL));

Related: input_direction(), apply_velocity().

Polar movement

advance()

Signatures
advance(object: RuntimeObject): void;

Advances this frame using the live linear velocity. In polar mechanics it also adds the vector defined by angle and speed; if polar speed is zero, it retrieves the speed declared when the instance was created. Applies the movement step. Does not apply acceleration again. Integrates delta internally.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
function motion(object) {
  advance(object);
}

Related: accelerate(), apply_velocity().

accelerate()

Signatures
accelerate(object: RuntimeObject, intent?: number): void;

Accelerates and moves in the same call; intent defaults to 1 when omitted and is clamped to [-1, 1]. With positive acceleration it adds an impulse to velocity, oriented by angle and limited by mechanics.motion.speed.limit, then moves using that velocity. With zero acceleration it uses speed and angle; if speed is zero, it retrieves originSpeed × intent. Movement respects step. Do not add advance to represent the same displacement or multiply by delta again.

object: RuntimeObject
Instance received or resolved during the current hook.
intent?: number
Numeric intent clamped to [-1, 1].

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
function motion(object) {
  accelerate(object, 1);
}

Related: advance(), apply_speed().

rotate()

Signatures
rotate(object: RuntimeObject, intent?: number): void;

Integrates rotation this frame. Intent defaults to 1 and is clamped to [-1, 1]. With angular acceleration it accumulates angular velocity; without it, it uses live rotationSpeed, or the declared initial speed when that value is zero. Respects the rotation limit and step. Delta is already included.

object: RuntimeObject
Instance received or resolved during the current hook.
intent?: number
Numeric intent clamped to [-1, 1].

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
rotate(object, -1);

Related: apply_angle(), apply_rotation_speed().

Live state

apply_speed()

Signatures
apply_speed(object: RuntimeObject, value: number): void;

Sets speed immediately, applying the mechanics.motion.speed.limit magnitude limit when configured. In direct mode, if the current linear velocity is nonzero, it also rescales it using the effective value; in polar mode it changes speed without replacing the linear vector. Does not move anything on its own.

object: RuntimeObject
Instance received or resolved during the current hook.
value: number
Value to assign.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
apply_speed(object, object.speed + 5);

Related: restore_speed(), apply_velocity().

apply_velocity()

Signatures
apply_velocity(object: RuntimeObject, direction: number, speed: number): void;

Replaces velocityX/velocityY with a vector whose direction is in FLX degrees and whose magnitude is speed. Applies the declared magnitude limit. Does not modify angle, rotationSpeed, speed, acceleration or inertia, and does not move immediately. In polar mode, advance can add angle/speed movement to this vector.

object: RuntimeObject
Instance received or resolved during the current hook.
direction: number
Direction in FLX degrees.
speed: number
Magnitude or speed, depending on the operation.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
apply_velocity(object, random(0, 360), random(20, 70));

Related: advance(), apply_speed().

Movement relationships

follow_x()

Signatures
follow_x(object: RuntimeObject, target: RuntimeObject): void;

Moves object toward a live RuntimeObject target along X, by at most abs(speed) × delta per call, without overshooting. Preserves the other axis. Does not accept a name or create a persistent relationship: query again and call in the frames where needed.

object: RuntimeObject
Instance received or resolved during the current hook.
target: RuntimeObject
Live instance to follow.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
const target = find_name("ball")[0];
if (target) follow_x(object, target);

Related: find_name(), attach().

attach()

Signatures
attach(object: RuntimeObject): void;

Enables the declared attach rules relative to the original parent; does not select a new parent. Captures the current position difference as the new live offset for the followed axes. World applies X, Y and/or angle following according to the declaration; following angle copies the parent's angle. Does not change the original creation offset. Enabling the flag without following rules does not invent new axes.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
attach(object);

Related: detach(), attach_active().

detach()

Signatures
detach(object: RuntimeObject): void;

Disables attach following, preserving the current position and angle. Retains the structural relationship with the parent and the original creation offset; an independent inherit.live.angle rule may continue to copy the angle.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
detach(object);

Related: attach(), find_parent().

attach_active()

Signatures
attach_active(object: RuntimeObject): boolean;

Returns the object's current attach flag. This boolean does not guarantee that a live parent exists or that an axis to follow has been declared.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: boolean.

JavaScript example

Related: attach(), detach().

carry()

Signatures
carry(object: RuntimeObject, carrier: RuntimeObject): void;

Adds to the object the displacement made by carrier in the current frame (current position minus previous position). This is a one-time operation; it does not create a persistent link. Repeated calls add that displacement again.

object: RuntimeObject
Instance received or resolved during the current hook.
carrier: RuntimeObject
Instance whose frame displacement is applied.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
carry(object, other);

Related: attach(), collision().
