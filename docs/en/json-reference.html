FLX Documentation

JSON Reference

This section documents the JSON structures used by FLX to define the main runtime structure, objects and their properties.

FLX is under active development. Some fields may change during the 0.x versions.

JSON Types

FLX currently uses different JSON files depending on their role inside the runtime.

  • main: defines the main runtime entry point.
  • node: defines a container that can contain other elements.
  • drawable: defines objects that can be visually represented.

Main JSON

The main file organizes the base runtime structure.

world.json
{
    "$schema": "tools/schemas/main.schema.json",
    "name": "Main",
    "description": "This is a description.",

    "screen": {
        "title": "Title in window",
        "width": 320,
        "height": 180
    },

    "scale": 3,

    "children": [ ... ],

    "spawns": { ... },

    "program": {
        "scripts": [ "scripts/program" ]
    }
}

Fields

  • $schema: schema path used for validation. [ Optional ]
  • name: logical name of the main structure. [ Required ]
  • description: optional description. [ Optional ]
  • screen: window or runtime surface configuration. [ Required ]
  • scale: rendering scale factor. [ Optional ]
  • children: list of structures loaded by the main structure. [ Optional ]
  • spawns: declarative spawn definitions associated with the object. [ Optional ]
  • program: scripts associated with the program. [ Optional ]

Screen

The screen block defines the basic window properties.

screen
"screen": {
    "title": "Title in window",
    "width": 320,
    "height": 180
}
  • title: window title. [ Optional ]
  • width: internal reference width. [ Required ]
  • height: internal reference height. [ Required ]

Children

The children field allows declaring objects contained by the main structure.

children (link)
"children": [ "objects/tofu" ]
children (inline)
"children": [ {"name": "Tofu", ... } ]
children (mix)
"children": [ "objects/tofu" , {"name": "Tofu", ... }, ... ]

Each value references an object that the runtime should load.

It can reference an external file (the JSON extension is not required) or be declared inline.

Program

The program field allows declaring scripts associated with the program logic.

program
"program": {
    "scripts": [ "scripts/program" ]
}

Fields

  • scripts: list of JavaScript scripts loaded for the object (extension not required).

Node JSON

A node defines a group of objects. It is not visually rendered but can contain logic.

tofu.json
{
    "$schema": "tools/schemas/node.schema.json",
    "name": "Level",
    "description" : "This is a description.",

    "children": [...],

    "spawns": {...}
}

Fields

  • $schema: schema path used for validation. [ Optional ]
  • name: logical name of the main structure. [ Required ]
  • description: optional description. [ Optional ]
  • children: list of objects loaded by the main structure. [ Optional ]
  • spawns: declarative spawn definitions associated with the object. [ Optional ]

Drawable JSON

A drawable file defines an object that can be visually represented.

tofu.json
{
    "$schema": "../tools/schemas/drawable.schema.json",
    "name": "Tofu",

    "origin": {
        "x": 157,
        "y": 87
    },

    "shape": {
        "type": "triangle",
        "color": "WHITE",
        "size": {
            "width": 18,
            "height": 24
        }
    },

    "motion": {
      "inherit": "creation",
      "rotationSpeed": 180,
      "acceleration": 120,
      "inertia": 0.99,
      "maxSpeed": 180
    },

    "bounds": {
      "mode": "wrap",
      "overflow": true
    },

    "spawns": {
        "laser": {
            "prefab": "objects/laser",
            "offset": {
                "x": 0,
                "y": -12
            }
        }
    },

    "group": "paddle",

    "behavior": {
        "scripts": [ "tofu" ]
    }
}

Fields

  • $schema: schema path used for validation. [ Optional ]
  • name: logical object name. [ Required ]
  • origin: initial object position. [ Optional ]
  • shape: visual object information. [ Optional ]
  • motion: movement configuration, if present. [ Optional ]
  • bounds: object behavior when reaching the screen boundaries. [ Optional ]
  • spawns: declarative spawn definitions associated with the object. [ Optional ]
  • group: logical group associated with the object. [ Optional ]
  • behavior: scripts associated with the object. [ Optional ]

Origin

Defines the initial object position inside the runtime.

origin
"origin": {
    "x": 157,
    "y": 87
}

Fields

  • x: X coordinate (relative to the coordinate origin, top-left corner). [ Required ]
  • y: Y coordinate (relative to the coordinate origin, top-left corner). [ Required ]

Shape

Defines the basic visual representation of the object.

shape
"shape": {
    "type": "triangle",
    "color": "WHITE",
    "size": {
        "width": 18,
        "height": 24
    }
}

Fields

  • type: shape type to render. [ Optional ]
    • block: default solid block. Rotation mechanics are not applied.
    • rectangle: rectangle with support for rotation and directional movement.
    • triangle: unfilled triangle.
    • line: line defined between two points.
    • text: renderable text.
  • color: object color. [ Optional ]
  • size: object size. [ Optional ]

Size

Defines the object size.

size
"size": {
    "width": 18,
    "height": 24
}

Fields

  • width: object width in pixels.
  • height: object height in pixels.

Motion

Defines properties related to object movement.

motion
"motion": {
    "inherit": "creation",
    "rotationSpeed": 180,
    "acceleration": 120,
    "inertia": 0.99,
    "maxSpeed": 180
}

Fields

  • inherit: defines how the spawned object inherits movement. [ Optional ]
    • none: no movement inheritance.
    • creation: inherits the initial movement at spawn time.
  • rotationSpeed: rotation speed.
  • acceleration: acceleration applied to the object.
  • inertia: movement preservation.
  • maxSpeed: maximum speed.

Bounds

Defines object behavior when reaching the screen boundaries.

bounds
"bounds": {
    "mode": "wrap",
    "overflow": true
},

Fields

  • mode: behavior mode. [ Optional ]
    • none: no special behavior.
    • wrap: when reaching a boundary, the object appears on the opposite side while preserving its direction.
  • overflow: controls how boundary behavior is applied. [ Optional ]
    • true: the object progressively disappears while appearing on the opposite side.
    • false: the object immediately reappears when reaching the boundary.

Spawns

Defines objects that can be dynamically instantiated from the runtime.

spawns
"spawns": {
    "laser": {
        "prefab": "objects/laser",

        "offset": {
            "x": 0,
            "y": -12
        }
    }
}

Spawn definitions use prefabs previously loaded by the runtime.

Fields

  • prefab: prefab path that should be instantiated. [ Required ]
  • offset: local offset applied to the spawn. [ Optional ]

The offset uses the current object rotation as reference.

Behavior

Defines scripts associated with the object.

behavior
"behavior": {
    "scripts": [ "tofu" ]
}

Fields

  • scripts: list of JavaScript scripts loaded for the object (extension not required). [ Required ]
