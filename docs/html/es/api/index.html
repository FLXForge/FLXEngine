Referencia pública JavaScript de FLX Engine v0.3.0. Si conoces tu objetivo, navega por familias. Si conoces un nombre, el índice A–Z te lleva a su referencia exacta. Las firmas usan la notación de flx.d.ts; los ejemplos son JavaScript.

Los parámetros con ? son opcionales. Los overloads comparten una referencia. Los hooks los implementa el desarrollador y los llama FLX; las demás funciones son operaciones disponibles para el script. Los ejemplos de fragmentos suponen un RuntimeObject válido object del hook actual y los nombres declarados que utilicen.
