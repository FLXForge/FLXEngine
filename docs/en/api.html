FLX Documentation

FLX API

This section documents the JavaScript functions exposed by FLX to the runtime.

FLX is under active development. Some functions may change during 0.x versions.

Constants

FLX exposes global constants to work with directions and keyboard keys in a readable way.

Direction

  • UP: upward direction.
  • DOWN: downward direction.
  • LEFT: left direction.
  • RIGHT: right direction.
  • STOP: neutral or stopped movement.

Keyboard

  • KEY_UP: up arrow.
  • KEY_DOWN: down arrow.
  • KEY_LEFT: left arrow.
  • KEY_RIGHT: right arrow.
  • KEY_SPACE: space bar.

RuntimeObject

Objects received by scripting functions are instances of RuntimeObject.

A RuntimeObject represents a living entity inside the runtime and contains both JSON-defined data and runtime-generated state.

RuntimeObject
function motion(ship) {

    ship.x += 10;

    console.log(ship.id);
}

id

Unique identifier assigned to the runtime instance.

Unlike name, every spawned object receives a unique identifier.

id
console.log(ship.id);

name

Logical object name.

It usually comes from the JSON definition.

name
console.log(ship.name);

local

Persistent state associated with a specific object instance.

Values stored inside object.local remain available while the object exists.

local
ship.local["timer"] += delta();

group

Logical group assigned to the object.

It can be used to classify entities and may be used by future filtering systems.

Position and Size

  • x: horizontal position.
  • y: vertical position.
  • width: width.
  • height: height.

Movement

  • speed: current speed.
  • originSpeed: initial speed.
  • velocityX: horizontal velocity.
  • velocityY: vertical velocity.
  • motion: motion configuration defined in JSON.

Origin

  • originX: initial X position.
  • originY: initial Y position.

angle

The angle property represents the object's current rotation in degrees.

FLX uses the following convention:

  • 0: up.
  • 90: right.
  • 180: down.
  • 270: left.

accelerate(object)

Applies acceleration to the object using its motion configuration. It takes into account acceleration, maxSpeed, angle, velocityX and velocityY.

accelerate
accelerate(ship);

Configuration Used

  • motion.acceleration: acceleration force.
  • motion.maxSpeed: maximum allowed speed.
  • angle: object's current direction.
  • velocityX and velocityY: accumulated velocity.

accelerate(object, amount)

Direct variant that adds a specific amount to speed. It does not use the advanced motion configuration.

accelerate amount
accelerate(ball, 20);

advance(object)

Moves the object according to its current configuration.

If the object has motion.acceleration greater than zero, it uses velocityX, velocityY and inertia. Otherwise it moves using angle and speed.

advance
function motion(ship) {
    advance(ship);
}

bounce_x(object)

Reverses horizontal movement by modifying the object's angle.

bounce_x
bounce_x(ball);

bounce_y(object)

Reverses vertical movement by modifying the object's angle.

bounce_y
bounce_y(ball);

console.log(...values)

Sends messages to the internal FLX logger.

console.log
console.log("Ship position:", ship.x, ship.y);

delta()

Returns the elapsed time, in seconds, since the previous frame.

It allows movement, timers and behaviors to be independent from frame rate.

timer
function motion(spawner) {

    spawner.local["timer"] += delta();

    if (spawner.local["timer"] > 3) {
        spawn(spawner, "asteroid");
        spawner.local["timer"] = 0;
    }
}

Draw_text(x, y, text, size)

Draws text on screen using logical screen coordinates.

Coordinates are expressed in FLX logical resolution. The engine applies the configured screen scale internally.

timer
draw_text( 10, 10, "HELLO ");
draw_text( 40, 10, "WORLD!", 15);

*size is optional, by dafault is 10.

follow_y(object, targetName)

Moves an object vertically to follow another object by name. It compares the vertical center of both objects and adjusts the Y position.

follow_y
follow_y(enemy, "Ball");

Configuration Used

  • y: object's vertical position.
  • height: object's height.
  • speed: follow speed.

Key.down(key)

Returns true while the specified key is being pressed.

Key.down
if (Key.down(KEY_UP)) {
    move_y(player, UP);
}

if (Key.down(KEY_LEFT)) {
    move_x(player, LEFT);
}

Key.pressed(key)

Returns true only on the frame the specified key begins being pressed.

Key.pressed
if (Key.pressed(KEY_SPACE)) {
    spawn(ship, "laser");
}

kill(object)

Marks an object for destruction.

The object is not removed immediately, but at the end of the current frame. This prevents modifications to the object list while the runtime is processing it.

Before final removal, the runtime will execute the dead(object) phase.

kill
function collision(object, other) {
    kill(object);
}

move_x(object, direction)

Moves the object horizontally using speed and frame time.

move_x
move_x(player, LEFT);
move_x(player, RIGHT);

move_y(object, direction)

Moves the object vertically using speed and frame time.

move_y
move_y(player, UP);
move_y(player, DOWN);

probability(chance, base)

Returns true randomly according to the specified probability.

If base is not specified, the default value is 100.

For example:

  • probability(30) → approximately 30 out of every 100 calls.
  • probability(20, 1000) → approximately 20 out of every 1000 calls.
probability
if (probability(5)) {
    spawn(object, "enemy");
}

if (probability(1, 1000)) {
    spawn(object, "rare_enemy");
}

random(min, max)

Returns a random value between min and max.

Useful for movement variation, procedural generation and dynamic behavior.

random
asteroid.angle = random(0, 360);

asteroid.speed = random(20, 80);

Parameters

  • min: minimum value.
  • max: maximum value.

rotate(object, direction)

Rotates the object using motion.rotationSpeed and frame time.

rotate
rotate(ship, LEFT);
rotate(ship, RIGHT);

spawn(object, childName)

Creates an instance of a manual child declared in the object's children block.

The childName parameter identifies which child definition should be instantiated.

Manual children use spawn: "manual" and may include local offsets.

The spawned object inherits the position and orientation required to correctly apply that offset.

spawn
if (Key.pressed(KEY_SPACE)) {
    spawn(ship, "laser");
}

Configuration Used

  • object: object performing the spawn.
  • childName: name of the manual child declared in JSON.

Internally, spawned objects are not inserted into the world immediately.

FLX uses a spawn queue to avoid modifying the object collection while the runtime is iterating over it.

to_origin(object)

Returns the object to its origin values. Restores x, y and speed using originX, originY and originSpeed.

to_origin
to_origin(ball);
