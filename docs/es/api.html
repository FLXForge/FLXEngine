FLX Documentation

FLX API

Esta sección documenta las funciones JavaScript expuestas por FLX al runtime.

FLX está en desarrollo activo. Algunas funciones pueden cambiar durante las versiones 0.x.

Constantes

FLX expone constantes globales para trabajar con direcciones y teclas de forma legible.

Dirección

  • UP: dirección hacia arriba.
  • DOWN: dirección hacia abajo.
  • LEFT: dirección hacia la izquierda.
  • RIGHT: dirección hacia la derecha.
  • STOP: movimiento neutro o detenido.

Teclado

  • KEY_UP: flecha superior.
  • KEY_DOWN: flecha inferior.
  • KEY_LEFT: flecha izquierda.
  • KEY_RIGHT: flecha derecha.
  • KEY_SPACE: barra espaciadora.

RuntimeObject

Los objetos recibidos por las funciones de scripting son instancias de RuntimeObject.

Un RuntimeObject representa una entidad viva dentro del runtime y contiene tanto datos definidos mediante JSON como estado generado durante la ejecución.

RuntimeObject
function motion(ship) {

    ship.x += 10;

    console.log(ship.id);
}

id

Identificador único de la instancia dentro del runtime.

A diferencia de name, cada objeto generado recibe un identificador exclusivo.

id
console.log(ship.id);

name

Nombre lógico del objeto.

Habitualmente proviene de la definición JSON.

name
console.log(ship.name);

local

Estado persistente asociado a una instancia concreta.

Los valores almacenados en object.local permanecen mientras el objeto exista.

local
ship.local["timer"] += delta();

group

Grupo lógico asociado al objeto.

Puede utilizarse para clasificar entidades o para futuros sistemas de filtrado.

Posición y tamaño

  • x: posición horizontal.
  • y: posición vertical.
  • width: ancho.
  • height: alto.

Movimiento

  • speed: velocidad actual.
  • originSpeed: velocidad inicial.
  • velocityX: velocidad horizontal.
  • velocityY: velocidad vertical.
  • motion: configuración de movimiento declarada en JSON.

Origen

  • originX: posición inicial X.
  • originY: posición inicial Y.

angle

La propiedad angle representa la rotación actual del objeto en grados.

FLX utiliza la siguiente convención:

  • 0: arriba.
  • 90: derecha.
  • 180: abajo.
  • 270: izquierda.

accelerate(object)

Aplica aceleración al objeto usando su configuración de motion. Tiene en cuenta acceleration, maxSpeed, angle, velocityX y velocityY.

accelerate
accelerate(ship);

Configuración utilizada

  • motion.acceleration: fuerza de aceleración.
  • motion.maxSpeed: velocidad máxima permitida.
  • angle: dirección actual del objeto.
  • velocityX y velocityY: velocidad acumulada.

accelerate(object, amount)

Variante directa que suma una cantidad concreta a speed. No utiliza la configuración avanzada de motion.

accelerate amount
accelerate(ball, 20);

advance(object)

Avanza el objeto según su configuración actual.

Si el objeto tiene motion.acceleration mayor que cero, utiliza velocityX, velocityY e inertia. Si no, avanza usando angle y speed.

advance
function motion(ship) {
    advance(ship);
}

bounce_x(object)

Invierte el movimiento horizontal modificando el ángulo del objeto.

bounce_x
bounce_x(ball);

bounce_y(object)

Invierte el movimiento vertical modificando el ángulo del objeto.

bounce_y
bounce_y(ball);

console.log(...values)

Envía mensajes al logger interno de FLX.

console.log
console.log("Ship position:", ship.x, ship.y);

delta()

Retorna el tiempo transcurrido, en segundos, desde el frame anterior.

Permite crear movimientos, temporizadores y comportamientos independientes de la velocidad de ejecución.

timer
function motion(spawner) {

    spawner.local["timer"] += delta();

    if (spawner.local["timer"] > 3) {
        spawn(spawner, "asteroid");
        spawner.local["timer"] = 0;
    }
}

Draw_text(x, y, text, size, color)

Dibuja texto en pantalla usando las coodenadas definidas en screen.

Las coordenadas son expresadas en FLX como coordenadas de resolución. El motor aplica la configuración de escalada de forma automática.

timer
draw_text( 10, 10, "HELLO ");
draw_text( 40, 10, "WORLD!", 15);
draw_text( 10, 30, "READY", 10, "#ffffff");

*size es opcional, por defecto es 10. color es opcional y usa blanco por defecto.

draw_pixel(x, y, color)

Dibuja un pixel inmediato en pantalla usando coordenadas logicas FLX. El motor aplica screen.scale internamente.

Es una funcion de dibujo de overlay, igual que draw_text(). No crea runtime objects, no colisiona y en esta version se dibuja por encima de los objetos del mundo.

pixels
function draw(space) {
    draw_pixel(4, 10);
    draw_pixel(10, 10, "white");
    draw_pixel(20, 20, "#ffcc00");
}

color es opcional y usa blanco por defecto. Acepta colores con nombre de FLX y valores hexadecimales.

fade_on(color)

Inicia un desvanecimiento de pantalla completa desde transparente hasta opaco. La superposicion se dibuja por encima del mundo y por encima del texto dibujado con draw_text().

El parametro color es opcional. Si no se indica, se usa negro. Se admiten colores con nombre y colores hexadecimales como #000 y #000000.

fade_on
fade_on();
fade_on("black");
fade_on("#000000");

La transicion dura actualmente un segundo y queda completamente cubierta al finalizar.

fade_off(color)

Inicia un desvanecimiento de pantalla completa desde opaco hasta transparente. Al terminar, la superposicion queda inactiva.

El parametro color es opcional y sigue las mismas reglas de color que fade_on().

fade_off
fade_off();
fade_off("black");
fade_off("#000000");

Los parametros de duracion e intensidad no forman parte de la API todavia. Quedan planteados como ampliaciones futuras.

fade_set(alpha, color)

Establece inmediatamente el alpha del fundido. 0 significa pantalla descubierta y 1 pantalla completamente cubierta. El valor se limita entre 0 y 1.

fade_set
function born(title) {
    fade_set(1);
    fade_off();
}

fade_set(0, "black");

El parametro color es opcional y usa negro por defecto.

fade_active()

Devuelve true mientras hay una transicion de fundido en curso. Devuelve false cuando el overlay esta estable.

fade_done()

Devuelve true cuando no hay ninguna transicion de fundido en curso. Sirve para continuar una transicion de escena de forma segura.

fade_alpha()

Devuelve el alpha actual del fundido.

transicion segura
function action(title) {
    if (Key.pressed(KEY_SPACE)) {
        title.local["leaving"] = 1;
        fade_on();
    }

    if (title.local["leaving"] == 1 && fade_done()) {
        // cargar siguiente escena
    }
}

follow_x(object, targetName)

Mueve un objeto horizontalmente hacia otro objeto. El objetivo se resuelve internamente por nombre. Solo modifica la posicion X del objeto.

follow_x
follow_x(cursor, "ball");

Configuracion utilizada

  • object: objeto que se mueve.
  • targetName: nombre logico de la instancia seguida.

follow_y(object, targetName)

Mueve un objeto verticalmente hacia otro objeto. El objetivo se resuelve internamente por nombre. Solo modifica la posicion Y del objeto.

follow_y
follow_y(enemy, "ball");

Configuración utilizada

  • object: objeto que se mueve.
  • targetName: nombre logico de la instancia seguida.

attach(object)

Activa las reglas de attach declaradas en JSON para el objeto. El objeto sigue solo a su parent original; no crea una nueva relacion de parent.

attach
attach(ball);

detach(object)

Desactiva las reglas de attach. El objeto conserva su posicion y angulo actuales.

detach
if (is_attached(ball) && Key.pressed(KEY_SPACE)) {
    detach(ball);
    ball.angle = -45;
}

is_attached(object)

Devuelve si el objeto esta unido actualmente a su parent original.

carry(object, carrier)

Aplica al objeto el desplazamiento del carrier durante el frame actual. No cambia parent, attach, offset, ownership ni collision.

carry
function collision(player, platform) {
    carry(player, platform);
}

Key.down(key)

Devuelve true mientras la tecla indicada está pulsada.

Key.down
if (Key.down(KEY_UP)) {
    move_y(tofu, UP);
}

if (Key.down(KEY_LEFT)) {
    move_x(tofu, LEFT);
}

Key.pressed(key)

Devuelve true solo en el frame en el que la tecla indicada empieza a pulsarse.

Key.pressed
if (Key.pressed(KEY_SPACE)) {
    spawn(ship, "laser");
}

kill(object)

Marca un objeto para ser destruido.

El objeto no se elimina inmediatamente, sino al final del frame actual. Esto evita modificar la lista de objetos mientras el runtime la está procesando.

Antes de la eliminación definitiva, el runtime ejecutará la fase dead(object).

kill
function collision(object, other) {
    kill(object);
}

keep_only(object)

Marca para destruccion todos los runtime objects vivos excepto el objeto exacto pasado como parametro. El objeto indicado se conserva, pero sus hijos no se conservan automaticamente.

Los objetos eliminados por keep_only() siguen el flujo normal de dead() y cleanup. El runtime no se modifica inmediatamente mientras los scripts estan iterando.

transicion de escena
function action(game) {
    if (global["startLevel"] == 1) {
        keep_only(game);
        spawn(game, "level1");
    }
}

move_x(object, direction)

Desplaza el objeto horizontalmente usando speed y el tiempo de frame.

move_x
move_x(tofu, LEFT);
move_x(tofu, RIGHT);

move_y(object, direction)

Desplaza el objeto verticalmente usando speed y el tiempo de frame.

move_y
move_y(tofu, UP);
move_y(tofu, DOWN);

ray(source, angle, distance)

Lanza un rayo invisible desde un runtime object y devuelve el impacto compatible mas cercano.

El rayo nace en source.position, usa coordenadas logicas FLX y sigue la misma convencion de angulo que advance(). No dibuja nada en pantalla.

ray
function motion(tank) {
    let sight = ray(tank, tank.angle, 200);

    if (sight.hit && sight.group == "player") {
        spawn(tank, "bullet");
    }
}

Valor devuelto

  • Sin impacto: { hit: false, group: "" }
  • Con impacto: { hit: true, group, distance, x, y }

Reglas de colision

  • El filtro de grupos sale de source.collision.with.
  • El objeto impactado no necesita collision.active = true.
  • Los objetos invisibles pueden ser detectados si su collision es valida.
  • Se ignoran el propio source, objetos muertos y tipos de collision no soportados.
  • Esta version soporta colisiones circle y box.

probability(chance, base)

Retorna true de forma aleatoria en función de la probabilidad indicada.

Si no se especifica base, el valor por defecto es 100.

Por ejemplo:

  • probability(30) → aproximadamente 30 de cada 100 llamadas.
  • probability(20, 1000) → aproximadamente 20 de cada 1000 llamadas.
probability
if (probability(5)) {
    spawn(object, "enemy");
}

if (probability(1, 1000)) {
    spawn(object, "rare_enemy");
}

play_sound(object, id)

Reproduce un sonido declarado en el bloque sounds del objeto.

El parametro id identifica la declaracion de sonido que pertenece a ese objeto.

play_sound
if (Key.pressed(KEY_SPACE)) {
    play_sound(ship, "laser");
    spawn(ship, "laser");
}

Configuracion utilizada

  • object: objeto que posee la declaracion de sonido.
  • id: nombre del sonido declarado en JSON.

random(min, max)

Retorna un valor aleatorio comprendido entre min y max.

Resulta útil para variaciones de movimiento, generación procedural y comportamiento dinámico.

random
asteroid.angle = random(0, 360);

asteroid.speed = random(20, 80);

Parámetros

  • min: valor mínimo.
  • max: valor máximo.

rotate(object, direction)

Rota el objeto usando motion.rotationSpeed y el tiempo de frame.

rotate
rotate(ship, LEFT);
rotate(ship, RIGHT);

spawn(object, childName)

Crea una instancia de un hijo manual declarado en el bloque children del objeto.

El parámetro childName identifica qué definición hija debe instanciarse.

Los hijos manuales usan spawn: "manual" y pueden incluir offsets locales.

El objeto generado hereda la posición y orientación necesarias para aplicar correctamente dicho offset.

spawn
if (Key.pressed(KEY_SPACE)) {
    spawn(ship, "laser");
}

Configuración utilizada

  • object: objeto desde el que se ejecuta el spawn.
  • childName: nombre del hijo manual declarado en el JSON.

Internamente, los objetos generados no se insertan inmediatamente en el mundo.

FLX utiliza una cola de spawn para evitar modificar la colección de objetos mientras el runtime la está recorriendo.

to_origin(object)

Devuelve el objeto a sus valores de origen. Restaura x, y y speed usando originX, originY y originSpeed.

to_origin
to_origin(ball);
