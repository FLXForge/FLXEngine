Without reference, coordinates are in the world's logical space. With a RuntimeObject as the first argument, they are local to its position and rotate with it. That spatial reference does not change the owner of the current draw. These are not physical coordinates multiplied by output.scale.

Immediate drawing

draw_text()

Signatures
draw_text(x: number, y: number, text: string, size?: number, color?: string): void;
draw_text(reference: RuntimeObject, x: number, y: number, text: string, size?: number, color?: string): void;

Emits immediate text during draw. x, y represent its center/pivot in logical coordinates. text is the content; size defaults to 10 when omitted, and color defaults to white. With reference, the position is local to that view and the text rotates with it. The primitive belongs to the owner of the current draw.

x: number
Logical X coordinate.
y: number
Logical Y coordinate.
text: string
Text to draw.
size?: number
Text size; 10 when omitted.
color?: string
Color as a string; for example "#ffffff".
reference: RuntimeObject
Local spatial reference; does not replace the draw owner.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
function draw(object) {
  draw_text(40, 10, "SCORE: " + (read_global("score") ?? 0));
  draw_text(object, 0, -12, "READY", 10, "#ffffff");
}

Related: draw(), RuntimeObject.

Runtime visual state

apply_color()

Signatures

Global fade

Fade belongs to the entire runtime, not to an instance. Its alpha and transition are global; fade_done only indicates the absence of a transition.

fade_on()

Signatures
fade_on(color?: string): void;

Starts a global transition from the current alpha to 1 (opaque), with a fixed duration of one second. Defaults to black. A new call restarts the transition from the alpha reached; do not call it every frame to initiate a single fade.

color?: string
Color as a string; for example "#ffffff".

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
function born(object) {
  fade_on("black");
}

Related: fade_off(), fade_set(), fade_done().

fade_off()

Signatures
fade_off(color?: string): void;

Starts a global transition from the current alpha to 0 (transparent), over one second. Defaults to black. To start with a fully covered screen, set alpha to 1 first.

color?: string
Color as a string; for example "#ffffff".

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
function born(object) {
  fade_set(1);
  fade_off();
}

Related: fade_on(), fade_alpha().

fade_set()

Signatures
fade_set(alpha: number, color?: string): void;

Immediately sets the global alpha clamped to [0, 1], cancels the active transition and sets the color (black by default). 0 leaves the scene visible; 1 covers it completely.

alpha: number
Opacity clamped to [0, 1].
color?: string
Color as a string; for example "#ffffff".

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
fade_set(0.5, "black");

Related: fade_active(), fade_alpha().

fade_active()

Signatures
fade_active(): boolean;

Returns true while a global fade transition is active.

Returns: boolean.

JavaScript example
if (fade_active()) console.log("Transition in progress");

Related: fade_done().

fade_done()

Signatures
fade_done(): boolean;

Returns true when no transition is active, even before starting a fade or after fade_set. Does not necessarily mean the screen is visible: the final alpha may be 1.

Returns: boolean.

JavaScript example
if (fade_done()) console.log("Alpha final:", fade_alpha());

Related: fade_alpha(), fade_active().

fade_alpha()

Signatures
fade_alpha(): number;

Returns the current global alpha between 0 and 1: transparent/visible at 0, fully covered at 1.

Returns: number.

JavaScript example
const alpha = fade_alpha();

Related: fade_set(), fade_done().
