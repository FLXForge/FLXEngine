FLX detects contacts and reports them to the script. It does not automatically apply a physical response. Detection is configured in JSON · Collision. The script decides what each contact means and how to respond to it.

Contacts

CollisionContact

Readonly data for a contact directed at object within the collision hook. This is not the return value of ray; for that, see RayHit.

Readonly fields

Normal, point and penetration: conceptual diagram
Source A                 Target B
┌──────────────┐
│       ┌──────┼──────────────┐
│       │   •  │              │
└───────┼──────┘              │
        └─────────────────────┘
        |<---->|
        penetration

• = contact point (pointX, pointY)
← = contact normal for A

correction for A = normal × penetration
The normal indicates direction; the point indicates location.

The diagram illustrates the concept, not a universal formula for choosing the geometric point. The related operation position() applies the contact correction to the source; its full reference is in Transform.

The example illustrates two pairs in one call. Do not rely on a fixed order or assume a single contact per pair. With is directional: notifying B requires its own rules and does not follow automatically from notifying A.

collision()

Signatures
collision(object: RuntimeObject, other: RuntimeObject, contacts: CollisionContact[]): void;

Hook implemented by the developer and called by FLX. object is the source, other is the target, and contacts collects their directed contacts in this call. Each source collider selects target groups through with; the target does not need reciprocal rules for the source to receive the callback. A pair of instances can generate multiple contacts through their different colliders. The script decides any separation, damage or reflection.

object: RuntimeObject
Instance received or resolved during the current hook.
other: RuntimeObject
Target instance of the contact.
contacts: CollisionContact[]
Contacts directed at the source in this call.

Returns: does not return a result to FLX (void).

JavaScript example
function collision(object, other, contacts) {
  for (const contact of contacts) {
    console.log(contact.collider, contact.otherCollider);
  }
}

Related: CollisionContact, position(), collider_off().

ray()

Signatures
ray(source: RuntimeObject, angle: number, distance: number): RayHit | undefined;

Runs a query from the logical position of source, with an angle in FLX degrees (0 up, 90 right) and a maximum distance in logical units. Returns the nearest hit against an effective collider, or undefined if there is no hit. Use a finite angle and distance; a zero distance produces no hit. Does not move anything or apply a physical response.

source: RuntimeObject
Origin instance for the query.
angle: number
Angle in FLX degrees.
distance: number
Maximum logical distance, finite and non-negative.

Returns: RayHit | undefined.

JavaScript example
const hit = ray(object, object.angle, 100);
if (hit) console.log(hit.object.id, hit.distance);

Related: RayHit, collider_on().

collider_on()

Signatures
collider_on(object: RuntimeObject, colliderName: string): void;

Enables the already declared collider named colliderName on the instance. Does not create new geometry; an unknown name does not add a collider. Its effectiveness still depends on the collision declaration. Does not modify visible.

object: RuntimeObject
Instance received or resolved during the current hook.
colliderName: string
Name of a declared collider.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
collider_on(object, "body");

Related: collision(), ray().
