JSON/Audio    → declaración de sounds/music

Machine/Audio → capacidades, voces y límites

Los identificadores se resuelven en los mapas del objeto. Consulta JSON · Audio para declarar sonidos y música, y Machine · Audio para sus límites. Aquí se documenta el control de reproducción, no la síntesis.

Sound · Music

Sound

play_sound()

Firmas
play_sound(object: RuntimeObject, id: string): void;

Solicita reproducir el sonido id declarado en sounds del objeto. No es una ruta de archivo arbitraria. Los sonidos pueden ocupar varias voces según Machine/Audio; sus límites y política de sustitución condicionan la reproducción. La llamada no devuelve un handle ni confirma que haya una voz disponible.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
id: string
Identificador descrito en esta referencia.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
play_sound(object, "laser");

Relacionados: play_music().

Music

play_music()

Firmas
play_music(object: RuntimeObject, id: string): void;

Solicita reproducir la música generada id declarada en music del objeto. Hay una música actual del runtime; al reproducir una nueva se sustituye la anterior. Sus capacidades y voces dependen de Machine/Audio.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
id: string
Identificador descrito en esta referencia.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function born(object) {
  play_music(object, "theme");
}

Relacionados: pause_music(), stop_music().

pause_music()

Firmas
pause_music(): void;

Alterna pausa/reanudación de la música actual. No actúa sobre sonidos individuales.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
pause_music();

Relacionados: music_paused(), music_active().

stop_music()

Firmas
stop_music(): void;

Detiene la música actual del runtime. No elimina el objeto que la solicitó.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
stop_music();

Relacionados: play_music(), music_active().

music_active()

Firmas
music_active(): boolean;

Devuelve true mientras hay música actual activa, también cuando está pausada.

Retorno: boolean.

Ejemplo JavaScript
if (music_active()) console.log("Hay música actual");

Relacionados: music_paused().

music_paused()

Firmas
music_paused(): boolean;

Devuelve true cuando la música actual está pausada.

Retorno: boolean.

Ejemplo JavaScript
if (music_paused()) pause_music();

Relacionados: pause_music().
