Audio · Referencia JSON

Índice | Project | Object | Composition | Visual | Creation | Mechanics | Collision | Audio

Audio documenta los sonidos y la música declarados en un Object. Estos recursos describen contenido generado; su declaración no implica reproducción automática. Las capacidades de la Machine son externas a estos bloques y no se configuran aquí.

sounds

Mapa de identificadores a Sound inline o referencias relativas/FLX. Sin el bloque no hay sonidos declarados. Cada identificador puede reproducirse desde la API, por ejemplo play_sound(object, "beep").

sounds
{
  "sounds": {
    "beep": {
      "kind": {
        "note": 880
      },
      "duration": 0.1,
      "volume": 0.4
    }
  }
}

Sound

  • like — string. Opcional. Base reutilizable; véase Composition.
  • kind — objeto. Opcional. Fuente, nota y variación de frecuencia.
  • tone — objeto o referencia FLX. Opcional. Material, envolvente y espacio.
  • duration — number > 0. Default: 0.1. Duración en segundos.
  • volume — number de 0 a 1. Default: 0.4. Volumen declarado.
  • priority — integer. Default: 0. Prioridad disponible para la política de asignación de voces del runtime.

kind

  • source — objeto o referencia FLX. Default: oscillator, square, duty 0.5. Fuente generadora.
  • note — string, number u objeto frequency. Default del runtime: 440 Hz. Nota musical como A4, frecuencia numérica en Hz o {"frequency": 440}. También puede ser referencia FLX a uno de esos valores.
  • slide — number. Default: 0. Variación de frecuencia en Hz a lo largo del sonido. Un slide distinto de cero tiene prioridad sobre el deslizamiento rise/fall.
  • movement — objeto o referencia FLX. Default: type none, amount 0. Modulación declarada.
kind
{
  "sounds": {
    "laser": {
      "kind": {
        "source": {
          "type": "oscillator",
          "wave": "square"
        },
        "note": "A4",
        "slide": -200,
        "movement": {
          "type": "fall",
          "amount": 0.5
        }
      },
      "duration": 0.15
    }
  }
}

source

  • type — string: oscillator | noise | impact | pulse. Default: oscillator. Tipo de fuente. El parser fuerza wave=noise cuando type=noise.
  • wave — string: sine | square | triangle | saw | pulse | noise. Default: square. Forma de onda.
  • duty — number de 0.05 a 0.95. Default: 0.5. Ciclo útil de la onda de pulso.
source — dentro de kind o instrument
{
  "type": "pulse",
  "wave": "pulse",
  "duty": 0.25
}

movement

  • type — string: none | rise | fall | pulse | wobble | scatter | random. Default: none. Tipo de movimiento sonoro.
  • amount — number de 0 a 1. Default: 0. Intensidad normalizada.
movement
{
  "type": "wobble",
  "amount": 0.2
}

tone

Objeto o referencia FLX compartido por Sound e Instrument. Sus tres grupos son opcionales; al omitirlos se aplican los defaults siguientes.

material

  • brightness — number de 0 a 1. Default: 0.5. Brillo del material.
  • roughness — number de 0 a 1. Default: 0. Rugosidad.
  • noise — number de 0 a 1. Default: 0. Componente de ruido.
  • resonance — number de 0 a 1. Default: 0. Resonancia.
  • metal — number de 0 a 1. Default: 0. Componente metálica.

envelope

  • attack — number ≥ 0. Default: 0. Tiempo de ataque en segundos.
  • decay — number ≥ 0. Default: 0.05. Tiempo de caída en segundos.
  • sustain — number de 0 a 1. Default: 0. Nivel sostenido.
  • release — number ≥ 0. Default: 0. Tiempo de liberación en segundos.

space

  • mode — string: mono | stereo. Default: mono. Modo espacial declarado.
  • width — number de 0 a 1. Default: 0. Anchura declarada.
  • echo — number de 0 a 1. Default: 0. Cantidad de eco.

En el generador actual, echo se utiliza en la síntesis; mode y width se leen y conservan, pero la onda generada sigue siendo mono. Declarar stereo no garantiza salida estéreo en esta versión.

tone
{
  "material": {
    "brightness": 0.8,
    "noise": 0.1
  },
  "envelope": {
    "attack": 0.01,
    "decay": 0.05,
    "sustain": 0.2,
    "release": 0.03
  },
  "space": {
    "mode": "mono",
    "echo": 0.1
  }
}

music

Mapa de identificadores a Music inline o referencias relativas/FLX. Cada canción requiere channels, un objeto de canales nombrados. Sin el bloque no hay música declarada. La reproducción se solicita desde la API.

  • like — string. Opcional. Base reutilizable.
  • tempo — number > 0. Default: 120. Tempo en negras por minuto. El sintetizador utiliza al menos 1 BPM.
  • loop — boolean. Default: false. Repetición de la canción.
  • channels — objeto. Obligatorio. Mapa de canales.
music mínima
{
  "music": {
    "theme": {
      "tempo": 120,
      "loop": false,
      "channels": {
        "lead": {
          "notes": [
            "C4",
            "E4",
            "G4",
            "-"
          ]
        }
      }
    }
  }
}

channels

  • notes — array de strings. Obligatorio. Secuencia de notas de este canal.
  • instrument — objeto o referencia FLX. Opcional; defaults de Instrument. Fuente y timbre del canal.
  • wave — string: square | sine | triangle | saw | noise. Default: square si no hay otra fuente. Forma corta por canal. Si se declara, sustituye la wave de instrument.source.
  • volume — number de 0 a 1. Default: 1. Volumen del canal.
  • length — string: 1/1 | 1/2 | 1/4 | 1/8 | 1/16. Default: 1/4. Duración de cada entrada de notes, relativa a una redonda. Una negra (1/4) dura 60/tempo segundos.

notes

Las notas usan nombres de C a B con octava de 0 a 8, con sostenidos o bemoles admitidos por el conversor, por ejemplo C#4 y Db4. "-" y "" son silencios. "x" o "X" dispara una entrada de ruido solo en canales de ruido; en otros se ignora con aviso. Una nota inválida o fuera de instrument.range queda como silencio con aviso.

Canal de ruido
{
  "music": {
    "beat": {
      "channels": {
        "drum": {
          "wave": "noise",
          "length": "1/8",
          "notes": [
            "x",
            "-",
            "x",
            "-"
          ]
        }
      }
    }
  }
}

instrument

  • source — objeto o referencia FLX. Defaults de source. Fuente generadora; el mismo bloque que en Sound.
  • tone — objeto o referencia FLX. Defaults de tone. Material, envolvente y espacio.
  • play.legato — boolean. Default: false. Parámetro de interpretación conservado por el parser.
  • play.glide — number de 0 a 1. Default: 0. Parámetro de interpretación conservado por el parser.
  • play.vibrato — number de 0 a 1. Default: 0. Intensidad del vibrato aplicado a la frecuencia durante la síntesis.
  • range.min — string de nota. Default: C0. Límite inferior de las notas reproducibles.
  • range.max — string de nota. Default: B8. Límite superior de las notas reproducibles.

play y range son objetos opcionales. El generador actual comprueba range y aplica vibrato. Legato y glide se conservan, pero todavía no se aplican al cálculo de la onda: se documentan como declaración aceptada, sin atribuirles un efecto audible no implementado.

Instrumento de un canal
{
  "music": {
    "theme": {
      "channels": {
        "lead": {
          "instrument": {
            "source": {
              "type": "oscillator",
              "wave": "triangle"
            },
            "tone": {
              "envelope": {
                "attack": 0.01,
                "decay": 0.05,
                "sustain": 0.4,
                "release": 0.02
              }
            },
            "range": {
              "min": "C3",
              "max": "C6"
            }
          },
          "length": "1/4",
          "notes": [
            "C4",
            "E4",
            "G4"
          ]
        }
      }
    }
  }
}

Referencias de audio

Sound y Music completos admiten rutas relativas y FLX, y like. Las referencias anidadas a source, tone, movement, note e instrument utilizan /archivo o /archivo:miembro. Un string como "square" no sustituye a un objeto source: wave debe ser un campo de source.

Recursos externos
{
  "sounds": {
    "beep": "/audio/beep"
  },
  "music": {
    "theme": "audio/theme"
  }
}

Los schemas de Sound y Music son abiertos (additionalProperties: true) en varias estructuras. Esto permite propiedades adicionales al validar, pero no implica que el runtime las interprete. Esta referencia enumera los campos leídos por la implementación actual. Véase Composition.
