Mechanics

Las operaciones de movimiento integran el delta del frame. Las operaciones apply cambian estado vivo; follow y carry actúan en la llamada actual, mientras attach activa un seguimiento persistente declarado. Para colocar o redimensionar directamente consulta Transform.

Los ángulos FLX se expresan en grados: 0 arriba, 90 derecha, 180 abajo, 270 izquierda. La configuración de límites, aceleración, inercia y pasos está en JSON · Mechanics. Elige la operación que representa el movimiento deseado; combinar integradores en el mismo frame puede añadir desplazamientos.

Movimiento directo

move_horizontal()

Firmas
move_horizontal(object: RuntimeObject, intent: number): void;

Mueve sobre el eje X durante este frame y actualiza su velocidad viva. intent se limita a [-1, 1]. Con aceleración de eje acumula velocidad; sin ella utiliza intent × speed. Respeta límite, step y política diagonal declarados en mechanics. Con intención neutra, la aceleración/inercia declaradas determinan la retención de velocidad. Integra el delta internamente.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
intent: number
Intención numérica limitada a [-1, 1].

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
move_horizontal(object, input_direction(object, direction(0), HORIZONTAL));

Relacionados: input_direction(), apply_velocity().

Movimiento polar

advance()

Firmas
advance(object: RuntimeObject): void;

Avanza este frame con la velocidad lineal viva. En mechanics polar añade también el vector definido por angle y speed; si la speed polar está en cero, recupera la declarada al crear la instancia. Aplica el step de movimiento. No vuelve a aplicar aceleración. Integra el delta internamente.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function motion(object) {
  advance(object);
}

Relacionados: accelerate(), apply_velocity().

accelerate()

Firmas
accelerate(object: RuntimeObject, intent?: number): void;

Acelera y desplaza en la misma llamada; intent vale 1 si se omite y se limita a [-1, 1]. Con acceleration positiva suma a la velocidad un impulso orientado por angle y limitado por mechanics.motion.speed.limit, y después mueve usando esa velocidad. Con acceleration cero usa speed y angle; si speed es cero, recupera originSpeed × intent. El movimiento respeta step. No añadas advance para representar el mismo desplazamiento ni multipliques otra vez por delta.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
intent?: number
Intención numérica limitada a [-1, 1].

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function motion(object) {
  accelerate(object, 1);
}

Relacionados: advance(), apply_speed().

rotate()

Firmas
rotate(object: RuntimeObject, intent?: number): void;

Integra rotación este frame. Intent por defecto 1, limitado a [-1, 1]. Con aceleración angular acumula velocidad angular; sin ella usa rotationSpeed vivo, o la velocidad inicial declarada cuando éste es cero. Respeta límite y step de rotación. El delta ya está incorporado.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
intent?: number
Intención numérica limitada a [-1, 1].

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
rotate(object, -1);

Relacionados: apply_angle(), apply_rotation_speed().

Estado vivo

apply_speed()

Firmas
apply_speed(object: RuntimeObject, value: number): void;

Asigna speed inmediatamente, aplicando el límite de magnitud de mechanics.motion.speed.limit cuando está configurado. En modo direct, si la velocidad lineal actual no es nula, también la reescala con el valor efectivo; en polar cambia speed sin sustituir el vector lineal. No desplaza por sí misma.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
value: number
Valor que se asigna.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
apply_speed(object, object.speed + 5);

Relacionados: restore_speed(), apply_velocity().

restore_speed()

Firmas
restore_speed(object: RuntimeObject): void;

Restaura speed a su valor declarado al crear la instancia. No restaura por sí sola el vector de velocidad ni otros campos de mechanics.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
restore_speed(object);

Relacionados: apply_speed().

apply_velocity()

Firmas
apply_velocity(object: RuntimeObject, direction: number, speed: number): void;

Reemplaza velocityX/velocityY por un vector de dirección en grados FLX y magnitud speed. Aplica el límite de magnitud declarado. No modifica angle, rotationSpeed, speed, acceleration ni inertia, y no desplaza inmediatamente. En polar, advance puede sumar a este vector el movimiento de angle/speed.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
direction: number
Dirección en grados FLX.
speed: number
Magnitud o velocidad según la operación.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
apply_velocity(object, random(0, 360), random(20, 70));

Relacionados: advance(), apply_speed().

Firmas

Invierte la componente horizontal de velocity y refleja la dirección polar (angle = -angle). No separa los objetos ni modifica speed. Collision no la llama automáticamente.

Relaciones de movimiento

follow_x()

Firmas
follow_x(object: RuntimeObject, target: RuntimeObject): void;

Acerca object a un RuntimeObject vivo target sobre X, como máximo abs(speed) × delta por llamada, sin sobrepasarlo. Conserva el otro eje. No acepta un nombre ni crea una relación persistente: vuelve a consultar y llamar en los frames necesarios.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
target: RuntimeObject
Instancia viva hacia la que se sigue.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
const target = find_name("ball")[0];
if (target) follow_x(object, target);

Relacionados: find_name(), attach().

attach()

Firmas
attach(object: RuntimeObject): void;

Activa las reglas attach declaradas respecto al padre original; no elige un nuevo padre. Captura la diferencia de posición actual como nuevo offset vivo para los ejes seguidos. World aplica el seguimiento de X, Y y/o angle según la declaración; angle seguido copia el del padre. No cambia el offset original de creación. Activar el indicador sin reglas de seguimiento no inventa ejes nuevos.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
attach(object);

Relacionados: detach(), attach_active().

detach()

Firmas
detach(object: RuntimeObject): void;

Desactiva el seguimiento attach, conservando la posición y el ángulo actuales. Mantiene la relación estructural con el padre y el offset original de creación; una regla independiente de inherit.live.angle puede seguir copiando el ángulo.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
detach(object);

Relacionados: attach(), find_parent().

attach_active()

Firmas
attach_active(object: RuntimeObject): boolean;

Devuelve el indicador actual de attach del objeto. Este booleano no asegura que exista un padre vivo ni que se haya declarado un eje que seguir.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: boolean.

Ejemplo JavaScript

Relacionados: attach(), detach().

carry()

Firmas
carry(object: RuntimeObject, carrier: RuntimeObject): void;

Suma al objeto el desplazamiento que lleva realizado carrier en el frame actual (posición actual menos posición anterior). Es puntual; no crea un vínculo persistente. Llamarla repetidamente vuelve a sumar ese desplazamiento.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
carrier: RuntimeObject
Instancia cuyo desplazamiento de frame se aplica.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
carry(object, other);

Relacionados: attach(), collision().
