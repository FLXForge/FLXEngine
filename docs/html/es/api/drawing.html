Sin reference, las coordenadas son del espacio lógico del mundo. Con un RuntimeObject primero, son locales a su posición y giran con él. Esa referencia espacial no cambia quién es el owner del draw actual. No son coordenadas físicas multiplicadas por output.scale.

Dibujo inmediato

draw_text()

Firmas
draw_text(x: number, y: number, text: string, size?: number, color?: string): void;
draw_text(reference: RuntimeObject, x: number, y: number, text: string, size?: number, color?: string): void;

Emite texto inmediato durante draw. x, y representan su centro/pivote en coordenadas lógicas. text es el contenido; size vale 10 si se omite y color es blanco por defecto. Con reference, la posición es local a esa vista y el texto gira con ella. La primitiva pertenece al owner del draw actual.

x: number
Coordenada lógica X.
y: number
Coordenada lógica Y.
text: string
Texto que se dibuja.
size?: number
Tamaño de texto; 10 si se omite.
color?: string
Color como cadena; por ejemplo "#ffffff".
reference: RuntimeObject
Referencia espacial local; no sustituye al owner de draw.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function draw(object) {
  draw_text(40, 10, "SCORE: " + (read_global("score") ?? 0));
  draw_text(object, 0, -12, "READY", 10, "#ffffff");
}

Relacionados: draw(), RuntimeObject.

Estado visual runtime

Una Animation con keys activas de color tiene prioridad visual durante RUNNING, PAUSED y DONE. apply_color y restore_color siguen actualizando la base runtime: al retirar Animation se muestra esa base vigente, incluida la ausencia de color declarado. No se tiñen bitmap ni elementos con color propio. Esta capa no transforma draw_*, incluidos sus modos locales. Véase Animation y Visual.

apply_color()

Firmas
apply_color(object: RuntimeObject, color: string): void;

Sobrescribe el color visual vivo de la instancia con color, por ejemplo "#ff0000". No reescribe la representación declarativa JSON ni es el parámetro color de una primitiva inmediata.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
color: string
Color como cadena; por ejemplo "#ffffff".

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
apply_color(object, "#ff0000");

Relacionados: restore_color(), draw_text().

restore_color()

Firmas
restore_color(object: RuntimeObject): void;

Restaura el color visual y la presencia de color declarados al crear la instancia.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
restore_color(object);

Relacionados: apply_color().

Animation

Una instancia reproduce como máximo una animación declarada en Object.animations. Las ocho funciones reciben una vista RuntimeObject válida del callback actual. No se añaden propiedades mutables al objeto. Los controles devuelven undefined; los argumentos inválidos o nombres inexistentes emiten warning, dejan intacta la reproducción y permiten continuar. Las consultas inválidas devuelven null, false o 0 según su tipo.

Las keys parciales interpolan offset, rotación sin normalización angular, escala y color por componente; representation cambia discretamente, incluido []. La escala cero/negativa es válida. La transformación visual aplica escala → rotación animada → offset → transformación mundial con el pivot existente. No cambia campos espaciales, físicos ni lógicos.

from: base captura la base runtime; from: current captura únicamente las propiedades controladas por la nueva animación. En loop+base cada ciclo usa la referencia fija; loop+current acumula offset/rotación por ciclo, sin acumular escala, color ni representación. Las keys posteriores a duration se conservan pero no participan. Los colores se interpolan después de Machine, sin reproyección por frame. El orden persist:first → sección sustituible → persist:last también se aplica en ABSENT y tras stop.

World avanza Animation una sola vez junto a Timer después de collision. born inicia en tiempo cero; si el objeto ya existe al llegar a esa fase temporal, recibe el delta de ese update. hide no pausa; show y state_to no reinician. Los destruidos no avanzan; dead puede consultar el estado final antes de eliminar la instancia.

Límite de draw: play/pause/stop cambian estado y consultas inmediatamente, pero la representación de ese turno ya está capturada. El cambio visual aparece en la siguiente captura. Crear un objeto desde draw no consume delta hasta un update posterior. Ni draw ni las consultas avanzan el reloj; el dibujo inmediato mantiene sus reglas históricas.

animation_active()

animation_active(object)

Devuelve true en RUNNING o PAUSED; false en ABSENT y DONE.

animation_current()

animation_current(object)

Devuelve el nombre seleccionado, también en PAUSED/DONE, o null en ABSENT.

animation_done()

animation_done(object)

Devuelve true únicamente en DONE. Un loop nunca finaliza por tiempo.

animation_left()

animation_left(object)

Devuelve segundos restantes, congelados en PAUSED y 0 en ABSENT/DONE. Con loop es el resto del ciclo actual: en el límite exacto vuelve a duration.

animation_paused()

animation_paused(object)

Devuelve true únicamente en PAUSED.

pause_animation()

pause_animation(object)

Pausa RUNNING sin borrar tiempo ni apariencia. No es toggle; ABSENT, PAUSED y DONE no cambian.

play_animation()

play_animation(object, name)

El nombre debe ser una cadena no vacía declarada en el objeto. Desde ABSENT inicia; el mismo nombre en RUNNING no hace nada, en PAUSED reanuda sin recaptura y en DONE reinicia con nueva captura. Otro nombre sustituye inmediatamente usando su política from. DONE retiene la apariencia final hasta stop, reinicio o sustitución.

stop_animation()

stop_animation(object)

Retira toda la contribución, incluido el respaldo numérico, y vuelve a la base runtime actual con persist. Deja ABSENT; no marca DONE. Sobre ABSENT no hace nada.

function born(o) { play_animation(o, "demo"); }
function action(o) {
    if (animation_done(o)) stop_animation(o);
}

Microejemplos ejecutables

Fade global

Fade pertenece al runtime completo, no a una instancia. Su alpha y transición son globales; fade_done sólo indica ausencia de transición.

fade_on()

Firmas
fade_on(color?: string): void;

Inicia una transición global desde el alpha actual hasta 1 (opaco), con duración fija de un segundo. Color negro por defecto. Una nueva llamada reinicia la transición desde el alpha alcanzado; no la llames cada frame para iniciar un único fade.

color?: string
Color como cadena; por ejemplo "#ffffff".

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function born(object) {
  fade_on("black");
}

Relacionados: fade_off(), fade_set(), fade_done().

fade_off()

Firmas
fade_off(color?: string): void;

Inicia una transición global desde el alpha actual hasta 0 (transparente), durante un segundo. Color negro por defecto. Para partir de pantalla completamente cubierta, establece primero alpha 1.

color?: string
Color como cadena; por ejemplo "#ffffff".

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
function born(object) {
  fade_set(1);
  fade_off();
}

Relacionados: fade_on(), fade_alpha().

fade_set()

Firmas
fade_set(alpha: number, color?: string): void;

Asigna inmediatamente el alpha global limitado a [0, 1], cancela la transición activa y establece el color (negro por defecto). 0 deja visible la escena; 1 la cubre completamente.

alpha: number
Opacidad limitada a [0, 1].
color?: string
Color como cadena; por ejemplo "#ffffff".

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
fade_set(0.5, "black");

Relacionados: fade_active(), fade_alpha().

fade_active()

Firmas
fade_active(): boolean;

Devuelve true mientras hay una transición global de fade activa.

Retorno: boolean.

Ejemplo JavaScript
if (fade_active()) console.log("Transición en curso");

Relacionados: fade_done().

fade_done()

Firmas
fade_done(): boolean;

Devuelve true cuando no hay transición activa, incluso antes de iniciar un fade o tras fade_set. No significa necesariamente pantalla visible: el alpha final puede ser 1.

Retorno: boolean.

Ejemplo JavaScript
if (fade_done()) console.log("Alpha final:", fade_alpha());

Relacionados: fade_alpha(), fade_active().

fade_alpha()

Firmas
fade_alpha(): number;

Devuelve el alpha global actual entre 0 y 1: transparente/visible en 0, completamente cubierto en 1.

Retorno: number.

Ejemplo JavaScript
const alpha = fade_alpha();

Relacionados: fade_set(), fade_done().
