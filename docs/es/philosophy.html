FLX Documentation

Filosofía

FLX nace de una idea sencilla: obtener resultados rápidamente sin luchar contra el motor.

Muchas veces una idea simple termina atrapada entre configuraciones, herramientas complejas o arquitecturas difíciles de entender.

FLX busca reducir esa fricción.

El objetivo es poder construir una escena, un prototipo o un juego utilizando herramientas conocidas, estructuras claras y una curva de aprendizaje sencilla.

Basado en estándares

FLX evita sistemas propietarios innecesarios.

Los proyectos utilizan tecnologías comunes y accesibles:

  • JSON para escenas y datos
  • JavaScript para scripting
  • Formatos estándar para recursos
  • Estructuras simples y legibles

La intención no es ocultar cómo funciona el motor, sino permitir que el desarrollador comprenda y controle lo que ocurre.

Alto y bajo nivel

FLX proporciona herramientas de alto nivel para resolver comportamientos comunes rápidamente.

Pero también permite acceder a niveles más bajos del sistema cuando el proyecto necesita un comportamiento específico.

Existen pautas y estructuras recomendadas, pero no caminos cerrados.

Pequeño, claro y directo

FLX está especialmente pensado para:

  • Prototipos
  • Jams
  • Juegos arcade
  • Pequeños proyectos 2D
  • Ideas experimentales

FLX continúa evolucionando durante las versiones 0.x. Algunas estructuras y sistemas pueden cambiar con el tiempo.
