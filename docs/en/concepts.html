FLX Documentation

Core Concepts

FLX organizes projects through simple data structures, objects, transformations and clearly defined execution rules.

This section describes the fundamental concepts present in every FLX project.

Project

Every FLX project starts with a main file using the .flx extension.

This file acts as the project entry point.

Asteroids.flx
name:Asteroids
version:1.0
flxEngineVersion:0.1.0
main:game.json

From this file, the runtime loads the main structure, resources and required configuration.

Main

The main structure is the root of the runtime.

It organizes objects, resources and execution logic.

Depending on the project, it may represent:

  • A level
  • A menu
  • A loading screen
  • A presentation
  • A narrative sequence
  • A specific application state

FLX does not impose a specific interpretation.

Objects

Objects represent elements that exist inside the runtime.

An object may:

  • Be rendered
  • Move
  • Collide
  • Store data
  • Execute behavior through scripts

Objects are typically described using JSON.

ship.json
{
    "name": "Ship",

    "shape": {
        "type": "triangle"
    },

    "motion": {
        "maxSpeed": 180
    }
}

Shape Types

FLX provides several basic visual representations.

Type Origin
block Top-left corner
rectangle Center
triangle Center
line Center
text Text rendering

Colors can be declared directly from JSON.

shape.json
"shape": {
    "type": "triangle",
    "color": "WHITE"
}

Coordinate System

FLX uses a 2D coordinate system with its origin in the top-left corner of the screen.

  • x grows to the right.
  • y grows downward.
  • Moving up decreases y.
  • Moving down increases y.

Angle System

FLX uses its own angular convention.

  • 0° points up.
  • 90° points right.
  • 180° points down.
  • 270° points left.
  • Positive angles rotate clockwise.
rotation
rotate(ship, RIGHT);
advance(ship);

Motion

FLX combines a traditional speed-based system with acceleration and inertia.

Common motion-related properties include:

  • speed
  • velocityX
  • velocityY
  • acceleration
  • inertia
  • rotationSpeed

Movement functions automatically use the FLX angular convention.
