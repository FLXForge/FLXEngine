This page brings together two independent families: the state machine declared in JSON and each RuntimeObject's named timers. Changing state does not replace the script; the script queries state and decides which operations to perform.

State · Timers

State

Transitions are declared in JSON · states. A component without its own machine can resolve its parent's machine; queries and transitions act on that effective machine.

state_to()

Signatures
state_to(object: RuntimeObject, stateName: string): void;

Requests a transition to the stateName declared and permitted in the current state's next list. Without a valid machine or transition, preserves the state. When accepted, changes the current name and resets time to 0; state_entered identifies the first full frame afterward. Does not assign an arbitrary property or execute an automatic callback per state.

object: RuntimeObject
Instance received or resolved during the current hook.
stateName: string
Declared state name.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
if (state_active(object, "title") && input_pressed(object, button(0))) {
  state_to(object, "playing");
}

Related: state_current(), state_entered().

state_current()

Signatures
state_current(object: RuntimeObject): string;

Returns the current state name, or an empty string if there is no state machine.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: string.

JavaScript example
const state = state_current(object);

Related: state_to(), state_active().

state_active()

Signatures
state_active(object: RuntimeObject, stateName: string): boolean;

Returns true if there is a state machine and the current name matches stateName. Without a machine, returns false.

object: RuntimeObject
Instance received or resolved during the current hook.
stateName: string
Declared state name.

Returns: boolean.

JavaScript example
if (state_active(object, "playing")) advance(object);

Related: state_current().

state_entered()

Signatures
state_entered(object: RuntimeObject): boolean;

Returns true during the new state's first full frame. A transition requested in the current frame prepares this flag for the next one; it is not an event consumed by the first query.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: boolean.

JavaScript example
function action(object) {
  if (state_entered(object)) play_timer(object, "intro", 1);
}

Related: state_to(), state_time().

state_time()

Signatures
state_time(object: RuntimeObject): number;

Returns the seconds accumulated since entering the state, or 0 without a machine. In action/motion of the first full frame, returns 0. A v0.3.0 nuance: World updates time after collisions and before draw; a read from draw may already observe that frame's delta. A value of 0 is not guaranteed throughout all its phases.

object: RuntimeObject
Instance received or resolved during the current hook.

Returns: number.

JavaScript example
function action(object) {
  if (state_active(object, "playing") && state_time(object) > 5) {
    state_to(object, "finished");
  }
}

Related: state_entered().

Timers

A timer belongs to RuntimeObject + name and disappears with its owner. World updates Running timers automatically; Paused freezes the remaining time. Done remains observable until the timer is played, removed or destroyed.

play_timer()

Signatures
play_timer(object: RuntimeObject, timerName: string, duration?: number): void;

Starts, resumes or redefines a timer identified by object + timerName (a nonempty string). Duration is in seconds and must be finite and greater than 0. Without duration: Running is unchanged, Paused resumes, Done restarts with its known duration, and Absent is not created. With duration: Absent and Done start with that full duration; Running or Paused preserve elapsed time and become Running with left = new total duration − elapsed time. If that remainder is ≤ 0, they immediately become Done. Duration is neither remaining time nor a universal restart command.

object: RuntimeObject
Instance received or resolved during the current hook.
timerName: string
Nonempty name of the object's timer.
duration?: number
Total duration in seconds, finite and greater than 0; optional.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
play_timer(object, "gun", 5);
// In a later call: pause and resume.
pause_timer(object, "gun");
play_timer(object, "gun");

Related: pause_timer(), stop_timer(), timer_done().

pause_timer()

Signatures
pause_timer(object: RuntimeObject, timerName: string): void;

Pauses a Running timer, preserving its remaining time. Does not toggle: if Paused, Done or Absent, it does not start it.

object: RuntimeObject
Instance received or resolved during the current hook.
timerName: string
Nonempty name of the object's timer.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
pause_timer(object, "gun");

Related: play_timer(), timer_paused().

stop_timer()

Signatures
stop_timer(object: RuntimeObject, timerName: string): void;

Immediately removes the object's timer. It becomes Absent, not Done; you need a duration to create it again.

object: RuntimeObject
Instance received or resolved during the current hook.
timerName: string
Nonempty name of the object's timer.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
stop_timer(object, "gun");

Related: play_timer(), timer_done().

timer_active()

Signatures
timer_active(object: RuntimeObject, timerName: string): boolean;

Returns true for both Running and Paused; false for Done or Absent.

object: RuntimeObject
Instance received or resolved during the current hook.
timerName: string
Nonempty name of the object's timer.

JavaScript example

timer_paused()

Signatures
timer_paused(object: RuntimeObject, timerName: string): boolean;

Returns true only for Paused. Having no timer returns false.

object: RuntimeObject
Instance received or resolved during the current hook.
timerName: string
Nonempty name of the object's timer.

Returns: boolean.

JavaScript example
if (timer_paused(object, "gun")) play_timer(object, "gun");

Related: pause_timer().

timer_done()

Signatures
timer_done(object: RuntimeObject, timerName: string): boolean;

Returns true when the timer is Done: normally after running out, but also if play_timer redefines the total duration below the time already elapsed. Remains Done until played, removed or its owner is destroyed. Absent and stop_timer are not Done.

object: RuntimeObject
Instance received or resolved during the current hook.
timerName: string
Nonempty name of the object's timer.

Returns: boolean.

JavaScript example
if (timer_done(object, "gun")) {
  stop_timer(object, "gun");
}

Related: play_timer(), stop_timer().

timer_left()

Signatures
timer_left(object: RuntimeObject, timerName: string): number;

Returns the remaining seconds. In Paused, preserves that value; in Absent, removed or Done, returns 0. By itself, it does not distinguish absence from completion.

object: RuntimeObject
Instance received or resolved during the current hook.
timerName: string
Nonempty name of the object's timer.

Returns: number.

JavaScript example
const remaining = timer_left(object, "gun");

Related: timer_done(), timer_active().
