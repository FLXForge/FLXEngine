Getting Started

This section shows the minimum structure required to run an FLX project.

The goal is to understand how a project is organized, how its files relate to each other and how to execute a first functional runtime.

Minimal Structure

An FLX project can start with only a few files.

Project structure
Asteroids/
│
├── first.flx
├── world.json
├── tofu.json
└── tofu.js

Each file has a specific role inside the runtime.

Project File

Every project starts with a .flx file.

This file defines the project metadata, runtime configuration and root object.

first.flx
name=My first FLX
version=1.0
engine=0.2.0
root=world
title=My first FLX

Root Object

The root object organizes the rest of the active runtime logic and objects.

In this example, the root object represents a world containing a single object: a tofu block.

world.json
{
    "$schema": "https://flxforge.github.io/FLXEngine/schemas/object.schema.json",
    "children": {
        "tofu": "tofu"
    }
}

Object

Objects define data and properties used during execution.

An object can contain:

  • Shape
  • Movement
  • Scripts
  • Collisions
  • Custom data
tofu.json
{
    "$schema": "https://flxforge.github.io/FLXEngine/schemas/object.schema.json",

    "origin": {
        "x": 157,
        "y": 87
    },

    "shape": {
        "color": "white",
        "size": {
            "width": 18,
            "height": 24
        }
    },

    "behavior": {
        "scripts": [ "tofu" ]
    }
}

Scripts

Scripts use JavaScript to define behavior.

During runtime, FLX automatically executes specific lifecycle functions.

tofu.js
/// <reference path="https://flxforge.github.io/FLXEngine/scripts/flx.d.ts" />

function action(tofu) {
    if (Input.player(1).up()) {
        move_y(tofu, UP);
    }

    if (Input.player(1).down()) {
        move_y(tofu, DOWN);
    }

    if (Input.player(1).left()) {
        move_x(tofu, LEFT);
    }

    if (Input.player(1).right()) {
        move_x(tofu, RIGHT);
    }
}

Execution

Once the project files are defined, the runtime can be executed by indicating the .flx file.

Terminal
.\flx project.flx

If everything is correctly configured, the runtime will load the root object, initialize the objects and start the execution loop.

Our tofu will appear in the world we created and we will be able to move it using the arrow keys.
