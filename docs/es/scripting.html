FLX Documentation

Scripting

FLX utiliza JavaScript para definir comportamiento durante la ejecución del runtime.

Los scripts permiten reaccionar al ciclo de vida de los objetos, acceder al contexto del runtime y modificar propiedades en tiempo real.

FLX está en desarrollo activo. Algunas funciones y estructuras pueden cambiar durante las versiones 0.x.

Estructura básica

Un script FLX es un archivo JavaScript estándar.

Los scripts se asocian normalmente mediante el bloque behavior.

tofu.json
"behavior": {
    "scripts": [ "tofu" ]
}

El runtime cargará automáticamente:

script path
scripts/tofu.js

Reference

FLX proporciona definiciones TypeScript para facilitar autocompletado y validación en el editor.

tofu.js
/// <reference path="../tools/scripts/flx.d.ts" />

Esto permite utilizar ayudas de desarrollo en editores compatibles como Visual Studio Code.

Ciclo de vida

El runtime ejecuta automáticamente determinadas funciones cuando existen dentro del script.

lifecycle.js
function start(self) {}

function action(self) {}

function motion(self) {}

function collision(self, other) {}

function draw(self) {}

function end(self) {}

Funciones

  • start: llamada al inicializar el objeto.
  • action: lógica principal e inputs.
  • motion: movimiento y transformaciones.
  • collision: gestión de colisiones.
  • draw: lógica de dibujado adicional.
  • end: llamada antes de destruir el objeto.

Acceso a propiedades

Los scripts pueden acceder y modificar propiedades de los objetos.

properties.js
function action(self) {

    self.origin.x += 1;

    self.motion.maxSpeed = 250;
}

Esto permite combinar estructuras JSON con lógica dinámica durante la ejecución.

Program scripts

Los scripts también pueden asociarse al bloque program del principal.

world.json
"program": {
    "scripts": [ "scripts/program" ]
}

Estos scripts permiten implementar lógica global del runtime.

Buenas prácticas

  • Mantener scripts pequeños y especializados.
  • Separar lógica global y lógica de objeto.
  • Usar JSON para configuración y JavaScript para comportamiento.
  • Evitar modificar estructuras innecesariamente durante draw().
