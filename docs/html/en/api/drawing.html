Without reference, coordinates are in the world's logical space. With a RuntimeObject as the first argument, they are local to its position and rotate with it. That spatial reference does not change the owner of the current draw. These are not physical coordinates multiplied by output.scale.

Immediate drawing

draw_text()

Signatures
draw_text(x: number, y: number, text: string, size?: number, color?: string): void;
draw_text(reference: RuntimeObject, x: number, y: number, text: string, size?: number, color?: string): void;

Emits immediate text during draw. x, y represent its center/pivot in logical coordinates. text is the content; size defaults to 10 when omitted, and color defaults to white. With reference, the position is local to that view and the text rotates with it. The primitive belongs to the owner of the current draw.

x: number
Logical X coordinate.
y: number
Logical Y coordinate.
text: string
Text to draw.
size?: number
Text size; 10 when omitted.
color?: string
Color as a string; for example "#ffffff".
reference: RuntimeObject
Local spatial reference; does not replace the draw owner.

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
function draw(object) {
  draw_text(40, 10, "SCORE: " + (read_global("score") ?? 0));
  draw_text(object, 0, -12, "READY", 10, "#ffffff");
}

Related: draw(), RuntimeObject.

Runtime visual state

An Animation with active color keys has visual priority during RUNNING, PAUSED and DONE. apply_color and restore_color still update the runtime base: removing Animation reveals that current base, including absence of declared color. Bitmap and explicit element colors are not tinted. This layer does not transform draw_*, including local modes. See Animation and Visual.

Animation

An instance plays at most one animation declared in Object.animations. All eight functions accept a valid RuntimeObject view from the current callback. No mutable object properties are added. Controls return undefined; invalid arguments or unknown names warn, preserve playback and allow execution to continue. Invalid queries return null, false or 0 according to their type.

Partial keys interpolate offset, unnormalized rotation, scale and color independently; representation switches discretely, including []. Zero/negative scale is valid. Visual transforms apply scale → animated rotation → offset → world transform with the existing pivot. Spatial, physical and logical fields remain unchanged.

from: base captures the runtime base; from: current captures only properties controlled by the incoming animation. Loop+base uses a fixed reference each cycle; loop+current accumulates offset/rotation per cycle, without accumulating scale, color or representation. Keys beyond duration remain stored but inactive. Colors interpolate after Machine without per-frame reprojection. persist:first → replaceable section → persist:last order also applies in ABSENT and after stop.

World advances Animation once alongside Timer after collision. born starts at time zero; objects present at that temporal phase receive that update's delta. hide does not pause; show and state_to do not restart playback. Destroyed objects do not advance; dead may query the final state before removal.

draw limit: play/pause/stop change state and queries immediately, but that turn's representation is already captured. Visual changes appear at the next capture. Objects created from draw consume no delta until a later update. Neither draw nor queries advance the clock; immediate drawing retains its historical rules.

animation_active()

animation_active(object)

Returns true in RUNNING or PAUSED; false in ABSENT and DONE.

animation_current()

animation_current(object)

Returns the selected name, including PAUSED/DONE, or null in ABSENT.

animation_done()

animation_done(object)

Returns true only in DONE. A loop never finishes from elapsed time.

animation_left()

animation_left(object)

Returns remaining seconds, frozen in PAUSED and 0 in ABSENT/DONE. For loops this is the current cycle remainder: exactly at a boundary it returns duration.

animation_paused()

animation_paused(object)

Returns true only in PAUSED.

pause_animation()

pause_animation(object)

Pauses RUNNING without clearing time or appearance. Not a toggle; ABSENT, PAUSED and DONE remain unchanged.

play_animation()

play_animation(object, name)

The name must be a nonempty string declared on the object. ABSENT starts; the same name in RUNNING does nothing, in PAUSED resumes without recapture and in DONE restarts with a fresh capture. Another name replaces immediately using its own from policy. DONE retains final appearance until stop, restart or replacement.

stop_animation()

stop_animation(object)

Removes the entire contribution, including numeric fallback, revealing the current runtime base with persist. Leaves ABSENT, not DONE. Does nothing in ABSENT.

function born(o) { play_animation(o, "demo"); }
function action(o) {
    if (animation_done(o)) stop_animation(o);
}

Executable microexamples

Global fade

Fade belongs to the entire runtime, not to an instance. Its alpha and transition are global; fade_done only indicates the absence of a transition.

fade_on()

Signatures
fade_on(color?: string): void;

Starts a global transition from the current alpha to 1 (opaque), with a fixed duration of one second. Defaults to black. A new call restarts the transition from the alpha reached; do not call it every frame to initiate a single fade.

color?: string
Color as a string; for example "#ffffff".

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
function born(object) {
  fade_on("black");
}

Related: fade_off(), fade_set(), fade_done().

fade_off()

Signatures
fade_off(color?: string): void;

Starts a global transition from the current alpha to 0 (transparent), over one second. Defaults to black. To start with a fully covered screen, set alpha to 1 first.

color?: string
Color as a string; for example "#ffffff".

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
function born(object) {
  fade_set(1);
  fade_off();
}

Related: fade_on(), fade_alpha().

fade_set()

Signatures
fade_set(alpha: number, color?: string): void;

Immediately sets the global alpha clamped to [0, 1], cancels the active transition and sets the color (black by default). 0 leaves the scene visible; 1 covers it completely.

alpha: number
Opacity clamped to [0, 1].
color?: string
Color as a string; for example "#ffffff".

Returns: no value (undefined in JavaScript; void in the signature).

JavaScript example
fade_set(0.5, "black");

Related: fade_active(), fade_alpha().

fade_active()

Signatures
fade_active(): boolean;

Returns true while a global fade transition is active.

Returns: boolean.

JavaScript example
if (fade_active()) console.log("Transition in progress");

Related: fade_done().

fade_done()

Signatures
fade_done(): boolean;

Returns true when no transition is active, even before starting a fade or after fade_set. Does not necessarily mean the screen is visible: the final alpha may be 1.

Returns: boolean.

JavaScript example
if (fade_done()) console.log("Alpha final:", fade_alpha());

Related: fade_alpha(), fade_active().

fade_alpha()

Signatures
fade_alpha(): number;

Returns the current global alpha between 0 and 1: transparent/visible at 0, fully covered at 1.

Returns: number.

JavaScript example
const alpha = fade_alpha();

Related: fade_set(), fade_done().
