RuntimeObject es la vista temporal de una instancia de World. Sus propiedades permiten observar estado vivo; las operaciones de esta página y de Mechanics lo modifican. Una definición JSON y una instancia runtime tienen funciones distintas.

RuntimeObject

RuntimeObject

Una vista viva temporal durante el hook actual. Las lecturas reflejan cambios del runtime, pero no puedes conservar la vista para hooks posteriores: caduca al terminar la invocación o morir la instancia. dead() recibe expresamente un contexto final válido del objeto muerto durante ese hook.

No guardes RuntimeObject en estado local/global ni en variables para reutilizarlo en otros hooks. Guarda su id y resuélvelo de nuevo con find_id(). Las quince propiedades públicas son readonly: usa las operaciones de la API para modificar estado.

  const target = typeof id === "string" ? find_id(id) : undefined;

Estado local y global

ScriptValue

Tipo
type ScriptValue = number | boolean | string;

Valor escalar admitido por el estado local y global. undefined representa una lectura ausente, no un cuarto tipo almacenable. Para guardar una identidad usa string; para datos estructurados diseña claves escalares. Relacionados: write_local(), write_global(), save().

El estado local pertenece a una instancia. El estado global es compartido por el runtime. Ambos almacenan escalares en memoria; Persistence añade almacenamiento entre ejecuciones.

read_local()

Firmas
read_local(object: RuntimeObject, key: string): ScriptValue | undefined;

Lee la clave key del estado local de object. Devuelve el valor escalar guardado o undefined si la clave no existe. Este estado pertenece a esa instancia, no a todas las instancias de la definición.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
key: string
Clave del valor.

Retorno: ScriptValue | undefined.

Ejemplo JavaScript
const lives = read_local(object, "lives") ?? 3;

Relacionados: write_local(), ScriptValue.

write_local()

Firmas
write_local(object: RuntimeObject, key: string, value: ScriptValue): void;

Guarda o sustituye key en el estado local de la instancia. value sólo admite number, boolean o string; no guarda arrays, objetos ni vistas RuntimeObject. No escribe un archivo de persistencia.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
key: string
Clave del valor.
value: ScriptValue
Valor que se asigna.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
write_local(object, "targetId", other.id);

Relacionados: read_local(), find_id(), save().

read_global()

Firmas
read_global(key: string): ScriptValue | undefined;

Lee key del estado compartido del runtime. Devuelve un ScriptValue o undefined cuando no existe.

key: string
Clave del valor.

Retorno: ScriptValue | undefined.

Ejemplo JavaScript

Relacionados: write_global(), ScriptValue.

write_global()

Firmas
write_global(key: string, value: ScriptValue): void;

Guarda o sustituye una clave compartida durante la ejecución. value es number, boolean o string. Compartido no significa persistente en disco; usa save para conservarlo entre ejecuciones.

key: string
Clave del valor.
value: ScriptValue
Valor que se asigna.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
write_global("score", 100);

Relacionados: read_global(), save().

Búsqueda

find_id()

Firmas
find_id(id: string): RuntimeObject | undefined;

Resuelve un identificador de instancia durante el hook actual. Devuelve una vista RuntimeObject viva o undefined si la instancia no existe o ya no está viva. La vista obtenida vuelve a caducar al terminar el hook.

id: string
Identificador descrito en esta referencia.

Retorno: RuntimeObject | undefined.

Ejemplo JavaScript
const id = read_local(object, "targetId");
const target = typeof id === "string" ? find_id(id) : undefined;
if (target) follow_x(object, target);

Relacionados: RuntimeObject, find_name().

find_name()

Firmas
find_name(name: string): RuntimeObject[];

Busca todas las instancias vivas cuyo nombre lógico coincide con name, en orden de World. El array es una instantánea JavaScript, no una colección reactiva; sus elementos siguen siendo vistas temporales. Sin coincidencias devuelve [].

name: string
Nombre del archivo de persistencia, sin la extensión .flxsave.

Retorno: RuntimeObject[].

Ejemplo JavaScript
const balls = find_name("ball");
if (balls.length) follow_y(object, balls[0]);

Relacionados: find_id(), find_children().

find_parent()

Firmas
find_parent(object: RuntimeObject): RuntimeObject | undefined;

Devuelve el padre vivo de object o undefined. En dead, el objeto muerto es un contexto estructural válido, pero el padre devuelto debe seguir vivo.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: RuntimeObject | undefined.

Ejemplo JavaScript
const parent = find_parent(object);
if (parent) console.log(parent.id);

Relacionados: find_children(), dead().

find_children()

Firmas
find_children(object: RuntimeObject): RuntimeObject[];

Devuelve los hijos directos vivos, en orden de World. Excluye declaraciones todavía no instanciadas, objetos pendientes, nietos e hijos muertos. Es una instantánea JavaScript; no persistas sus RuntimeObjects.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: RuntimeObject[].

Ejemplo JavaScript
for (const child of find_children(object)) {
  hide(child);
}

Relacionados: find_parent(), spawn().

Transform

position()

Firmas
position(object: RuntimeObject, x: number, y: number): void;
position(object: RuntimeObject, contact: CollisionContact): void;

Con x, y, coloca la instancia en coordenadas lógicas absolutas. Con contact, suma a su posición actual normal × penetration del contacto dirigido al objeto. La corrección no modifica angle, speed ni velocity y no produce rebote. Usa un contacto cuyo source sea el objeto que corriges; varios contactos no constituyen por sí solos un solver físico.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
x: number
Coordenada lógica X.
y: number
Coordenada lógica Y.
contact: CollisionContact
Contacto dirigido al objeto que recibe la corrección.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
position(object, 160, 90);
// Dentro de collision(object, other, contacts):
if (contacts.length) position(object, contacts[0]);

Relacionados: CollisionContact, collision(), reflect_x().

position_origin()

Firmas
position_origin(object: RuntimeObject): void;

Restaura las coordenadas lógicas de origen de la instancia. No restablece velocidad, ángulo, tamaño ni estado local. Una relación attach activa puede volver a determinar la posición en su fase de actualización.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
position_origin(object);

Relacionados: position(), attach().

depth()

Firmas
depth(object: RuntimeObject, value: number): void;

Asigna la profundidad de dibujo (utiliza un valor entero). Los valores menores se dibujan primero. La vista JavaScript observa el nuevo valor inmediatamente; el pase de dibujo en curso conserva el orden capturado al iniciarse y el cambio de orden se aplica al siguiente pase.

object: RuntimeObject
Instancia recibida o resuelta durante el hook actual.
value: number
Valor que se asigna.

Retorno: sin valor (undefined en JavaScript; void en la firma).

Ejemplo JavaScript
depth(object, 10);

Relacionados: RuntimeObject, draw().
