Introducción

Un pequeño motor 2D basado en datos

Crea escenas con JSON, define comportamientos con JavaScript y deja que el núcleo en C++ haga el resto.

La filosofía FLX: obtener resultados rápidamente

En FLX, la escena, los objetos y los actores se definen mediante datos estructurados y ordenados en JSON.

scene.json
{
    "$schema": "../../../tools/schemas/drawable.schema.json",
    "name": "Ship",

    "shape": {
        "type": "triangle",
        "color": "WHITE",
        "size": {
            "width": 18,
            "height": 24
        }
    },

    "motion": {
        "rotationSpeed": 180,
        "acceleration": 120,
        "inertia": 0.99,
        "maxSpeed": 180
    }
}

Qué es. Dónde está. Cómo se construye.

La lógica del juego se maneja mediante scripts sencillos en JavaScript.

player.js
/// <reference path="../../../../tools/scripts/flx.d.ts" />

function action(self) {
    if (Key.up()) {
        accelerate(self);
    }
}

function motion(self) {
    advance(self);
}
