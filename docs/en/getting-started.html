FLX Documentation

Getting Started

This section shows the minimum structure required to run an FLX project.

The goal is to understand how a project is organized, how its files relate to each other and how to execute a first functional runtime.

Minimal Structure

An FLX project can start with only a few files.

Project structure
Asteroids/
│
├── first.flx
├── world.json
├── tofu.json
└── tofu.js

Each file has a specific role inside the runtime.

Main File

Every project starts with a .flx file.

This file defines the main project configuration and the runtime entry point.

first.flx
name:My first FLX
version:1.0
flxEngineVersion:0.0.1
main:world.json

Main

The main structure organizes the rest of the active runtime logic and objects.

In this example, the main structure represents a world containing a single object: a tofu block.

world.json
{
    "$schema": "../tools/schemas/main.schema.json",
    "name": "World",
    "description": "This is the world where Tofu lives.",

    "screen": {
        "title": "My first FLX",
        "width": 320,
        "height": 180
    },
    "scale": 3,

    "children": [ "tofu" ]
}

Object

Objects define data and properties used during execution.

An object can contain:

  • Shape
  • Movement
  • Scripts
  • Collisions
  • Custom data
tofu.json
{
    "$schema": "../tools/schemas/drawable.schema.json",
    "name": "Tofu",

    "origin": {
        "x": 157,
        "y": 87
    },

    "shape": {
        "color": "WHITE",
        "size": {
            "width": 18,
            "height": 24
        }
    },

    "behavior": {
        "scripts": [ "tofu" ]
    }
}

Scripts

Scripts use JavaScript to define behavior.

During runtime, FLX automatically executes specific lifecycle functions.

tofu.js
/// <reference path="../tools/scripts/flx.d.ts" />

function action(tofu) {
    if (Key.up()) {
        move_y(tofu, UP);
    }

    if (Key.down()) {
        move_y(tofu, DOWN);
    }

    if (Key.left()) {
        move_x(tofu, LEFT);
    }

    if (Key.right()) {
        move_x(tofu, RIGHT);
    }
}

Execution

Once the main files are defined, the runtime can be executed by indicating the .flx file.

Terminal
.\FlxEngine project.flx

If everything is correctly configured, the runtime will load the main structure, initialize the objects and start the execution loop.

Our tofu will appear in the world we created and we will be able to move it using the arrow keys.
