collisions

Optional map of names to colliders, or a reference to the entire map. Without collisions, no colliders are declared. Each entry can be an inline object or an FLX reference /archivo:miembro. Collision geometry is independent of visual.

collisions
{
  "group": "player",
  "size": {
    "width": 24,
    "height": 24
  },
  "collisions": {
    "body": {
      "type": "ellipse",
      "with": [
        "enemy",
        "wall"
      ]
    }
  }
}

Collider

Object with no required fields in the schema. An empty collider takes the defaults, but is only effective if its resolved dimensions are positive.

  • type — string: box | ellipse. Runtime default: box. Oriented rectangle or ellipse.
  • enabled — boolean. Runtime default: true. Initial enabled state.
  • size — object. Optional; each omitted axis takes Object.size. width and height, when declared, are numbers > 0.
  • offset — object. Default: x 0, y 0. Local displacement; each numeric axis is optional.
  • angle — number. Runtime default: 0. Degrees added to the object's angle.
  • with — array of unique nonempty strings. Default: empty. Actively queried groups.
  • states — nonempty array of unique nonempty strings. Optional; no filter. Effective states in which the collider is available.

Collider size

Axes are resolved separately. If a collider axis is missing and the Object has no logical size, that axis is 0 and the collider is ineffective. A visible representation does not automatically supply collider dimensions.

Collider with its own size
{
  "collisions": {
    "body": {
      "type": "box",
      "size": {
        "width": 16,
        "height": 24
      }
    }
  }
}

offset and angle

The center is the object's position plus the offset rotated by the object's angle. The effective angle adds object.angle + collider.angle. The collider offset is not the creation offset.

Offset geometry
{
  "size": {
    "width": 32,
    "height": 32
  },
  "collisions": {
    "sensor": {
      "offset": {
        "x": 0,
        "y": -20
      },
      "size": {
        "width": 12,
        "height": 8
      },
      "angle": 45,
      "with": [
        "enemy"
      ]
    }
  }
}

with

Each name is compared with the other object's group. An empty or omitted array does not initiate detection from that collider, although the collider may participate as the target of another that includes it in with. The filter is directional: the target collider does not need to declare the source's group. Belonging to an entity through component does not replace these filters or, by itself, suppress callbacks between its objects.

Passive collider
{
  "group": "wall",
  "size": {
    "width": 16,
    "height": 64
  },
  "collisions": {
    "body": {
      "type": "box"
    }
  }
}

Collider states

Filters by effective state: its own machine or, for a component without one, the machine found in its parent chain. If a filter exists but there is no effective state, the collider is unavailable. The filter combines with enabled and positive dimensions; it does not replace Object.states.

State-limited collider
{
  "size": {
    "width": 20,
    "height": 20
  },
  "states": {
    "initial": "idle",
    "idle": {
      "next": [
        "active"
      ]
    },
    "active": {
      "next": [
        "idle"
      ]
    }
  },
  "collisions": {
    "hit": {
      "with": [
        "enemy"
      ],
      "states": [
        "active"
      ]
    }
  }
}

Detecting a collision does not, by itself, apply a physical response: it does not automatically separate objects, change velocities or produce bounces. Collision callbacks and queries belong to FLX API.
